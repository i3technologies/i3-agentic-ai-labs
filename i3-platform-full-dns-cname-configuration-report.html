Recommended TTL: 300 seconds (5 minutes) for all new and updated records.
This allows you to correct any mistakes within 5 minutes during the setup window. Once all records are verified and stable (after 48 hours of confirmed operation), increase to 3600 seconds (1 hour) to reduce DNS query load. Do not use a lower TTL than 300 — some resolvers ignore values below 60 and it adds unnecessary query volume. Do not use the cPanel default of 14400 (4 hours) during initial setup — a wrong record would take 4 hours to correct globally.
