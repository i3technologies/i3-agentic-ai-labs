1. What is i3 AI Lab?

The i3 AI Lab is a managed JupyterHub environment that gives data scientists and ML engineers instant access to scalable notebook compute with full integration to the i3 platform's AI services — including the LiteLLM model gateway, ChromaDB vector database, and Ollama local model serving. Each user gets their own private, persistent Jupyter notebook environment.

4. Making LLM Calls from Your Notebook

Using the OpenAI SDK (Recommended)

from openai import OpenAI
import os

client = OpenAI(
    api_key=os.environ["LITELLM_KEY"],
    base_url=os.environ["LITELLM_URL"]
)

response = client.chat.completions.create(
    model="qwen-fast",   # or qwen-heavy, qwen-coder, granite-nano, vision
    messages=[
        {"role": "system", "content": "You are a helpful data analyst."},
        {"role": "user", "content": "Summarise the key metrics in this dataset."}
    ]
)
print(response.choices[0].message.content)

5. Working with ChromaDB (Vector Database)

Querying an Existing Collection

import chromadb
import os

client = chromadb.HttpClient(
    host=os.environ["CHROMA_HOST"],
    headers={"Authorization": f"Bearer {os.environ['CHROMA_TOKEN']}"}
)

# List available collections
print(client.list_collections())

# Query the admissions knowledge base
collection = client.get_collection("admissions-kb")
results = collection.query(
    query_texts=["What are the requirements for Computer Science?"],
    n_results=3
)
print(results["documents"])

Creating Your Own Collection

# Create a new collection for your experiment
my_collection = client.create_collection("my-experiment-kb")

# Add documents
my_collection.add(
    documents=["Document text here", "Another document"],
    ids=["doc1", "doc2"]
)

print("Collection created with", my_collection.count(), "documents")
Note: Do not modify production collections (admissions-kb, pmaas-manifesto, afroerp-kb) from your notebook. Create your own namespaced collection for experiments.

6. Managing Your Files

  • Your home directory (/home/jovyan) is mounted on a 5 GB persistent volume. Files are preserved between sessions.
  • Use the JupyterLab file browser (left panel) to upload, download, rename, and organise files.
  • To upload a file: drag and drop into the file browser, or click the Upload button (↑ icon).
  • To download a file: right-click the file in the browser → Download.
  • Do not store sensitive data (passwords, keys, personal data) in notebook files — they may appear in Langfuse traces if passed to LLM calls.
Storage management: Monitor your storage usage via the Storage indicator in JupyterLab's status bar. When approaching 5 GB, archive or download old notebooks to free space.

7. Installing Additional Python Packages

You can install packages in your notebook session. To make them persist across server restarts, install to your user directory:

!pip install --user pandas-profiling seaborn langchain
Note: Installed packages survive server restarts within your personal server, but if your server pod is recreated (e.g. after a platform upgrade), packages may need to be reinstalled. For frequently used packages, ask your administrator to add them to the shared base image.

8. Server Management

Starting / Stopping Your Server

  • To stop your server (free up resources when not in use): Click File → Hub Control Panel → Stop My Server.
  • To restart: Go back to https://jupyter.i3technologies.co.ke and log in — your server will start automatically.
  • Idle servers are automatically stopped after 1 hour of inactivity to conserve cluster resources. Your files are not affected.

Session Timeout

If you see "Your server is not running" — click Start My Server. Your 5 GB workspace and all saved notebooks will be exactly as you left them.
