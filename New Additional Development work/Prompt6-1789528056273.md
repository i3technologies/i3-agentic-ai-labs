OBJECTIVE:
Architect a downloadable developer CLI tool and workspace daemon called `i3-code` (analogous to Claude Code, OpenAI Codex, or Devin) that developers run from their local terminal/workstation to autonomously interact with the i3 AI Platform and the i3 Sovereign AI Appliance (i3-SAA).

SPECIFICATIONS:
1. Client CLI Architecture (`i3-code`):
   - Terminal UI (Node.js/Ink or Go/Bubbletea) with real-time streaming tokens and action diffs.
   - Authentication: OIDC device authorization code flow against our Keycloak endpoint (`sso.i3technologies.co.ke`).
   - Operating Modes: 
     * `Ask` (Read-only explanations & architecture review)
     * `Plan` (Generates a markdown execution plan, files changed, and tool invocations for human review)
     * `Agent` (Bounded autonomous execution within granted scopes)

2. Backend Runtime on i3 AI Platform:
   - Client communicates with a dedicated `i3-ar-server` running on ROKS.
   - Model Gateway: Routes requests through `i3-model-gateway` (LiteLLM) using Granite 4.x for routing/syntax, Qwen for coding, and Granite Guardian for output compliance.
   - Tool Bus (MCP): Implements Model Context Protocol clients connecting to remote cluster MCP servers (Postgres DB inspector, OpenShift `oc` runner, GitOps trigger).
   - Action Registry & Risk Tiers:
     * Tier 0: Read local repo / workspace files.
     * Tier 1: Generate/diff proposed code changes.
     * Tier 2: Write code / run local unit tests in sandbox.
     * Tier 3: Apply migrations to `sit_db` / `talent_db` on Crunchy Postgres.
     * Tier 4: Trigger ArgoCD/Tekton production deployment (requires human MFA approval).

DELIVERABLE:
Provide the full project directory layout, configuration schema (`i3-code.config.yaml`), Keycloak client definition, and a sequence diagram detailing a developer requesting:
"Build and deploy the 001_init.sql schema migration for Talent Cloud to PostgreSQL via MCP."
