Vision

i3 SmartLab is an AI-native content authoring platform where educators and instructional designers create SCORM-compliant courses, interactive digital books, and live/on-demand video lessons — all powered by the multimodal AI models already running in i3-model-gateway. Once authored, content flows automatically to i3EduBridge (Moodle LMS) for learner delivery and to OvenMediaEngine for live streaming or VOD playback — with zero manual re-encoding.

Everything built on what already exists. No new external SaaS. No new cloud vendors. Every component reuses live i3 platform services: LiteLLM (AI), SeaweedFS (storage), OvenMediaEngine (streaming), Moodle (LMS), Directus (content API), n8n (automation), Keycloak (auth), and the existing i3-data PostgreSQL cluster.

Live Class Streaming Flow

OvenMediaEngine is already live at 149.81.34.82 with RTMP (1935), SRT (9999/udp), WebRTC (3333/3334), and LL-HLS (8080). The ABR ladder is configured: 1080p/4Mbps · 720p/2Mbps · 480p/800kbps · 240p/300kbps. SmartLab Live simply wraps this with an instructor UI and Keycloak auth.
Instructor authenticates via Keycloak SSO → receives a short-lived RTMP stream key from the SmartLab API (stored in Vault, scoped to the course).
Instructor streams from OBS / browser (WebRTC) → RTMP ingest at rtmp://live.i3technologies.co.ke:1935/live/{stream-key} → OME transcodes to 4-rung ABR ladder in real-time.
Learners watch at https://cdn.i3technologies.co.ke/hls/live/{stream-key}_720p/index.m3u8 embedded inside i3EduBridge (Moodle activity) or directly in the SmartLab player.
AI Tutor sidebar (powered by qwen-fast) answers learner questions during the live session in real-time — with full context of the course syllabus loaded from ChromaDB.
n8n automation detects stream end → triggers STT transcription → AI chapter detection → VOD package → auto-publishes to Moodle course as a recording.
xAPI events (watched, paused, completed, quiz-answered) fire to Langfuse LRS → aggregated in Grafana learning analytics dashboard.

SCORM Compliance — Technical Detail

SCORM 1.2

imsmanifest.xml with organizations + resources. API shim in JS (LMSInitialize, LMSSetValue, LMSCommit, LMSFinish). CMI data model: cmi.core.lesson_status, cmi.core.score.raw, cmi.suspend_data.

SCORM 2004 (4th Ed)

imscp_v1p1 manifest. SCORM 2004 API: Initialize, SetValue, Commit, Terminate. Sequencing & Navigation: AI can set prerequisite rules between SCOs based on quiz pass rates.

xAPI / Tin Can

Every learner interaction emits an xAPI statement: Actor.verb.object. Stored in Langfuse as the LRS. Enables cross-platform tracking: video watch depth, AI tutor queries, quiz retries.

Moodle SCORM Activity

SCORM ZIP uploaded to i3EduBridge via Moodle's mod_scorm. Grading, completion criteria, and prerequisites managed inside Moodle. No plugin required for standard SCORM delivery.

Smart Author Workflow — Step by Step

Login: Author signs in to author.i3technologies.co.ke via Keycloak SSO. Role-based access: Admin, Author, Reviewer, Publisher.
New Course: Click "Create with AI" → enter topic, learning level (beginner/intermediate/advanced), duration (e.g. 2 hours), target language. Select output: SCORM, EPUB, or Video.
AI Drafts: qwen-fast generates course outline with modules, lessons, and learning objectives aligned to Bloom's taxonomy. Author reviews and edits each section in a rich-text editor (Tiptap).
Enrich Multimodally: Upload existing slides / PDFs / images → vision model auto-captions and embeds them. TTS generates narration for each slide automatically. STT transcribes any audio reference material.
Build Assessments: Click "Generate Quiz" on any lesson → qwen-fast produces 5–10 MCQs with distractors, hints, and explanations. Author edits, shuffles, or adds custom questions. Branching logic defined per SCORM 2004 sequencing rules.
Preview: One-click SCORM preview launches an in-browser SCORM player (SCORM.js runtime) with full CMI tracking to confirm course logic works before publish.
Publish to LMS: SmartLab API packages the SCORM ZIP → uploads to i3EduBridge via Moodle web service API → creates/updates Moodle course activity automatically. No manual file transfer.
Publish to OTT: If course contains video → SmartLab API pushes to SeaweedFS S3 → triggers n8n workflow → OME creates VOD stream → Nginx HLS CDN serves it → Moodle activity updated with stream URL.
Go Live: For live classes, author clicks "Start Live Session" → SmartLab generates RTMP key from Vault → provides OBS stream URL → Moodle learners see the live player embedded in their course page.
Analytics: Post-session, author opens the Grafana learning dashboard → sees completion rates, quiz scores, video watch depth, AI tutor session count, drop-off points — all from xAPI events in Langfuse.

Innovative Differentiators

One Prompt → Full Course

Type "Introduction to Soil Science for secondary school" → get a complete 12-module SCORM course with slides, narration, quizzes, and learning objectives in under 3 minutes.

Content Reuse Intelligence

The embed model indexes every course in ChromaDB. When authoring, SmartLab surfaces semantically similar slides, quizzes, and videos from your entire content library — eliminating duplicate work.

Live → VOD — Zero Effort

The moment an instructor ends a live class, n8n fires automatically: transcribe, chapter, subtitle, transcode, publish to Moodle as a recording. No manual steps needed.

Adaptive AI Tutor in Every Lesson

The granite-nano model is pre-loaded with the course syllabus. Learners get instant, contextually accurate answers during both live streams and VOD — not generic ChatGPT responses.

Multimodal Book Creation

Upload a Word document → AI rewrites it as a textbook with inserted illustrations (vision model), read-aloud audio (TTS), embedded quizzes, and accessible EPUB3 — in one pipeline run.

Bloom's Taxonomy Alignment

The authoring API automatically tags every learning objective and quiz question to the correct Bloom's level (Remember → Create). Instructional designers get auto-QA on cognitive load distribution.

Infrastructure Cost Impact

No new IBM Cloud costs. SmartLab runs in a new i3-smartlab namespace on the existing 12-node ROKS cluster which currently has ~12 vCPU and ~77 GB RAM headroom. SeaweedFS S3, OME, Nginx CDN, Moodle, Keycloak, LiteLLM, STT/TTS, Langfuse, and PostgreSQL are all already running and paid for. The only new resource is the SmartLab API (~0.5 vCPU / 1 GB) and Studio UI (~0.25 vCPU / 512 MB) — well within headroom.
