🔵 Langfuse Prisma DIRECT_URL was causing DB auth failures
Root cause identified and fixed: DIRECT_URL was set to the primary Postgres host without SSL, and PGO enforces SCRAM-SHA-256. Unsetting it forces Prisma to use DATABASE_URL (pgbouncer with sslmode=require) for all queries. Migrations remain disabled (LANGFUSE_AUTO_POSTGRES_MIGRATION_DISABLED=true) — the schema was pre-created and is healthy.
🔵 Stale build pods in i3-evalos
Several old build pods in Error state exist (evalos-web-6, 9, 10, 14, 15). These are harmless but can be cleaned up: oc delete pod -n i3-evalos -l openshift.io/build.name (selecting failed ones).
