Date: 10 September 2026  ·  Cluster: IBM ROKS 4.17, eu-de (Frankfurt), 12 × bx2.4x16 nodes, 192 GB RAM  ·  Constraint: IBM Credits = Compute only. 100% open-source AI stack.  ·  Scope: i3 Internal Platform + Commercial Products + AI Lab + PMaaS + AfroERP + i3-Engage  ·  Note: 8 Customer Solution deployments are EXCLUDED — separate server.
1 Strategic Context & Architecture Principles
Core Mandate: Build a fully commercialisable, open-source AI platform on IBM ROKS compute. Every service must be licensable, white-labelable, or offered as SaaS. The platform serves: (1) i3 internal operations, (2) commercial AI product suite (PMaaS, AfroERP, i3-Engage, EvalOS, AI Lab), (3) training — Bootcamps, Agentic AI Summit, Hackathons, Customer Workshops. The 8 customer solution deployments run on a separate server and are referenced here only for integration points.
Key architectural decision: Every customer-facing solution gets an AI Co-worker (chat + voice + tools sidebar), an autonomous agent layer for background tasks, and a multimodal interface (text, voice, image). All AI runs through a single LiteLLM gateway so models can be swapped without touching application code.

4 AI Co-worker — The Universal Interface
Every product gets an AI Co-worker — a Claude-like persistent chat+tools sidebar embedded in the app UI. Built on Open WebUI (MIT, self-hosted, white-labelable). Each product has its own white-labelled instance with its own system prompt, tool set, and RAG corpus. All route through LiteLLM gateway.
Features — All Products
💬 Chat Interface
Streaming responses, markdown rendering, code blocks with copy, conversation history, context window management.
🎤 Voice Mode
Push-to-talk via Whisper STT → LLM → XTTS-v2 TTS. Full voice conversation in browser. Swahili + English.
📎 File Upload
Upload PDF, DOCX, images → parsed and injected into context or indexed into ChromaDB for RAG.
🔧 Tools Sidebar
Per-product tools: web search, code executor, database queries, API calls, calendar, document generation.
🤖 Agent Mode
Switch between chat (single-turn), RAG (retrieval-augmented), and Agent (multi-step autonomous task execution).
📊 Model Switcher
Users can select: Fast (Qwen 7B), Code (Qwen-Coder 7B), Heavy (Qwen 14B), Vision (LLaVA). All via LiteLLM.
