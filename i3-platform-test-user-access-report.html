Activation Steps

Two methods available: Use Method A (Kubernetes CR) when deploying a fresh cluster with the RHSSO Operator. Use Method B (PowerShell script) when Keycloak is already live and you need to add users immediately.

Method A — Kubernetes CR (declarative, GitOps-managed)

# Apply the KeycloakUser CRs to the cluster
oc apply -f platform/operators/keycloak/test-users.yaml

# Verify the RHSSO operator reconciled all 4 users
oc get keycloakusers -n i3-auth

Method B — PowerShell script (imperative, works on live cluster)

# Prerequisites: cluster logged in, Keycloak running
. .\platform\scripts\load-env.ps1
$env:KEYCLOAK_ADMIN_PASSWORD = "<admin-password>"

# Run the provisioning script
.\platform\scripts\provision-test-users.ps1

Verify users were created

# List all i3technologies.co.ke accounts in the realm
oc exec -n i3-auth $(oc get pods -n i3-auth -l app=keycloak \
  -o jsonpath='{.items[0].metadata.name}') -- \
  curl -s 'http://localhost:8080/admin/realms/i3/users?max=20' \
  -H 'Authorization: Bearer <admin-token>' | \
  python3 -c "import sys,json; [print(u['username'], u['email']) for u in json.load(sys.stdin)]"
