Essential Day-1 Commands

Ordered Execution Sequence
# 1. Bootstrap infrastructure
make init-infra    # init Terraform with COS remote backend
make plan-infra    # review changes
make deploy-infra  # provision VPC, ROKS, COS, IAM

# 2. Deploy operators (manual OpenBao unseal required after)
make deploy-operators

# 3. Deploy all application workstreams (sync wave order enforced by Argo CD)
make deploy-apps

# 4. Verify everything is healthy
make verify-cluster

# 5. Run full test suite
make test-all

# 6. GPU ops (on-demand)
make gpu-up        # activate for training / heavy inference
make gpu-down      # return to $0 idle cost

# 7. DR validation
make dr-test       # non-destructive backup integrity check
