3. Diagnostic Analysis

Why Admissions Relevancy failed (0.41 vs 0.75 target)

Root cause: single-sentence context density. The admissions RAG contexts are 1–2 sentence summaries. The heuristic proxy evaluator measures question keyword coverage in the answer — when the ground-truth answer restates the question using synonyms rather than exact keywords (e.g. "entry requirements" answered with "STEM bachelor's degree, Python proficiency"), the overlap drops sharply. This is a proxy measurement artefact, not a true agent failure. The real RAGAS run (live agent + LLM-based NLI for faithfulness) will score higher because the semantic NLI model handles paraphrase.
  • Worst relevancy items: "What are the entry requirements…" (0.00), "Are group discounts available…" (0.00), "What is the expected weekly time commitment…" (0.00)
  • Common pattern: answers use domain-specific noun phrases (STEM, JupyterHub, MLOps) not directly repeated in the question stem
  • Action: No RAG config change needed. Schedule live RAGAS run via Tekton ragas-eval task from inside the cluster once the gateway TLS issue is resolved

Why PMaaS Faithfulness failed (0.53 vs 0.80 target)

Root cause: short contexts missing numeric/technical tokens. PMaaS contexts like "max_tokens=1400 for /briefing endpoint" and "retrieve_context(question, n_results=4)" are highly abbreviated. The faithfulness heuristic requires 40% of answer words to appear in the context blob — but the ground-truth answers expand these abbreviations into full sentences, causing zero token overlap on 3 pairs.
  • Zero-faithfulness items:
    • "What is the maximum token budget…" — context has max_tokens=1400; answer says "capped at 1400 tokens"
    • "What autonomy tier…" — context has autonomy_tier=L1; answer expands to full sentence
    • "How many top-k results…" — context has n_results=4; answer says "retrieves 4 results"
  • Action: Expand context strings in PMAAS_RAGAS_DATASET to include natural language alongside technical notation — this is a dataset quality issue, not an agent RAG issue
