1. Single Sign-On (SSO) — All Users All Roles

🔑

Keycloak SSO

https://sso.i3technologies.co.ke
Single login gateway for all i3 Platform applications. Log in once, access everything.

First Login

  1. Navigate to https://sso.i3technologies.co.ke/realms/i3/account
  2. Enter the username and temporary password provided by your administrator.
  3. You will immediately be asked to create a new password.
  4. Password requirements:
    • Minimum 12 characters
    • At least one uppercase letter, one lowercase letter
    • At least one digit and one special character
  5. After changing your password, you are taken to the Account Portal.

Account Portal — What You Can Do

Visit https://sso.i3technologies.co.ke/realms/i3/account to:

  • Update your personal details (name, email)
  • Change your password → Account Security → Signing In → Password
  • Set up a 2FA authenticator app (TOTP) → Account Security → Signing In → Set up Authenticator
  • Review active sessions and revoke access from unknown devices → Device Activity
  • View which applications you have authorised → Applications

Accessing Any Application

Simply navigate to any i3 application URL. You are redirected to SSO automatically. Once authenticated, the session lasts up to 10 hours and is shared across all i3 applications — no need to log in again.

Forgotten Password

  1. On any application's login page, click Forgot Password?
  2. Enter your registered email address.
  3. Check your inbox for a reset link (valid for 15 minutes).
  4. Click the link and set your new password.
Session Timeout: Your session expires after 10 hours of inactivity. If you are in an EvalOS exam when it expires, your answers are automatically saved — just log in again and click Resume.

2. EvalOS — AI-Enhanced Assessment Platform Students

📝

EvalOS Exam Engine

https://evalos.i3technologies.co.ke
Secure exam platform with isolated Firecracker sandbox VMs for live code execution. MCQ, short-answer, and coding questions.

Getting Started

  1. Navigate to https://evalos.i3technologies.co.ke — you are redirected to SSO.
  2. Log in with your i3 credentials.
  3. Your Dashboard shows:
    • Upcoming exams with countdown timers
    • Past attempts and scores
    • Available practice exercises

Starting an Exam

  1. Click the exam name on your Dashboard.
  2. Read the rules and duration on the pre-exam screen carefully.
  3. Click Begin Exam.
  4. The platform automatically:
    • Locks your browser into fullscreen mode
    • Randomises question order and shuffles MCQ answer options
    • Starts the countdown timer
Do not exit fullscreen or switch tabs during an exam. These events are logged. After 3 fullscreen exits or 5 focus losses, your attempt is flagged for instructor review.

The Exam Interface

PanelContents
LeftQuestion list with progress indicators — green = answered, grey = skipped
CentreCurrent question: MCQ options, short answer text box, or code editor
RightCountdown timer, Submit Exam button, reference materials (if provided)

Submitting Code (Coding Questions)

  1. Type or paste your code in the code editor (centre panel).
  2. Click Run Tests to execute your code against the visible test cases in a secure sandbox VM.
  3. Results appear below the editor: pass/fail per test case, standard output, and execution time.
  4. You may revise and re-run as many times as you like before the timer expires.
  5. Click Submit Question to lock your final answer for that question.
Sandbox boot time: Each VM boots in ~125 ms. Execution time-limit per run is 30 seconds.

Execution Environments

ProfileEnvironmentUsed For
APython 3.11 + PyTorch + HuggingFaceAI/ML coding tasks
BTerraform + kubectl (dry-run)IaC / DevOps tasks
CRust / C++ / ROS 2Systems programming
DDual-VM security labCybersecurity practicals

Anti-Cheat Monitoring

EvalOS monitors your browser behaviour during exams. The following events are logged:

EventFlag Threshold
Window focus lost (switching away)5 events before flag
Fullscreen exit3 events before flag
Clipboard events (copy / paste)10 events before flag
Tab switchLogged every occurrence
Being flagged does not immediately disqualify you. Your instructor reviews the flag before any decision is made.

If Your Exam Is Interrupted

If your browser crashes, power cuts out, or your internet drops:

  1. Return to https://evalos.i3technologies.co.ke and log in.
  2. Your Dashboard shows the in-progress attempt.
  3. Click Resume — your answers and timer state are fully restored from the server.

Viewing Your Results

After your instructor publishes grades:

  1. Go to My Results on the Dashboard.
  2. Click any attempt to see: overall score, pass/fail, per-question breakdown, sandbox execution output, and instructor comments.

3. AI Lab — JupyterHub Workbench Students & Instructors

🔬

AI Lab — JupyterHub

https://jupyter.i3technologies.co.ke
Personal Jupyter notebook workbenches with GPU access for AI/ML coursework and research. Powered by Red Hat OpenShift AI.

Accessing Your Workbench

  1. Navigate to https://jupyter.i3technologies.co.ke.
  2. Log in via SSO (your i3 credentials).
  3. Select your notebook image:
    • PyTorch 2.x — for deep learning
    • TensorFlow 2.x — for Keras/TF projects
    • Minimal Python — for general coursework and data science
  4. Choose a container size (your instructor sets the maximum available):
    • Small: 2 CPU / 4 GB RAM
    • Medium: 4 CPU / 8 GB RAM / 0.5 GPU
    • Large: 8 CPU / 16 GB RAM / 1 GPU
  5. Click Start Server. Wait 30–60 seconds for initialisation.

Saving Your Work

  • Your home directory (/opt/app-root/src) is a persistent volume — files survive server restarts.
  • Do not store datasets larger than 5 GB in your home directory — use the shared S3 bucket instead.
  • Commit notebooks to your Git repository regularly.
  • Temporary large checkpoints should go to /tmp.

Using the LiteLLM AI API from Your Notebook

import openai

client = openai.OpenAI(
    api_key="<your-litellm-api-key>",   # Request from your instructor
    base_url="http://litellm-proxy.i3-model-gateway.svc.cluster.local:4000"
)

response = client.chat.completions.create(
    model="granite-nano",    # Tier 3: fast, always-warm
    messages=[{"role": "user", "content": "Explain gradient descent"}]
)
print(response.choices[0].message.content)

Stopping Your Workbench

Always stop your server when not in use to free cluster resources (especially GPU).
  1. Click your username in the top right → Log Out.
  2. On the JupyterHub control panel, click Stop My Server.

5. Admissions AI Chatbot Prospective Students

🎓

Admissions Assistant

https://admissions.i3technologies.co.ke
AI-powered chatbot for programme enquiries, fees, schedules, and booking admissions calls. No login required.

Starting a Conversation

  1. Navigate to https://admissions.i3technologies.co.ke — no login required.
  2. Type your question in the chat box and press Enter or click Send.
  3. The assistant responds in real time with streaming tokens.
  4. Continue the conversation — it remembers what you asked within the session.

What the Assistant Can Help With

  • Programme descriptions, modules, and entry requirements
  • Fee structures, payment plans, and scholarship options
  • Application deadlines and intake dates
  • Student services, campus facilities, and support

Booking an Admissions Call

Ask the assistant to book a call. It will:

  1. Ask for your name, email, preferred date, and time.

  • Answer questions outside admissions and programme topics

11. n8n Workflow Automation Instructors & Admins

⚡

n8n Automation Engine

https://n8n.i3technologies.co.ke
No-code workflow automation for post-class content processing, enrolment, notifications, and CMS integrations.

Logging In

Navigate to https://n8n.i3technologies.co.ke and log in with your i3 SSO credentials.

Pre-Built Workflows

1. OTT Post-Class Pipeline (Automatic)

Runs automatically when a live stream ends:

  1. Receives the stream name and recording path from OvenMediaEngine
  2. Runs FFmpeg ABR transcode into 4 quality levels
  3. Generates AI subtitles via Whisper
  4. Uploads to SeaweedFS VOD bucket
  5. Creates/updates the Directus CMS record
This workflow runs automatically — you do not need to trigger it. Monitor its status in n8n → Executions.

2. Auto-Enrolment Workflow (Automatic)

Triggered when a student passes an EvalOS admissions assessment:

  1. Receives student data from EvalOS
  2. Creates a cohort namespace if it does not exist
  3. Sends a welcome email with login credentials
  4. Creates a CRM record

3. Manual Content Pipeline Trigger

If a recording was missed by the automatic webhook:

  1. Open OTT Post-Class Pipeline in n8n.
  2. Click Execute Workflow.
  3. Fill in stream_name and recording_path.
  4. Click Run.

Creating a New Workflow

  1. Click + New Workflow in the top right.
  2. Search for nodes in the left panel (e.g. "HTTP Request", "Postgres", "Send Email").
  3. Connect nodes by dragging from one output to the next input.
  4. Use Test Step to validate each node individually.
  5. Click Save then Activate to enable automatic triggering.

12. LiteLLM API — For Developers Developers

🤖

LiteLLM Model Gateway

https://litellm.i3technologies.co.ke
OpenAI-compatible API proxy for all i3 AI models. Request your personal API key from your instructor or administrator.

Requesting an API Key

Ask your instructor or IT administrator for a personal LiteLLM API key. Keys have per-model access restrictions and budget caps set by your administrator.

Making API Calls

import openai

client = openai.OpenAI(
    api_key="sk-litellm-YOUR-KEY-HERE",
    base_url="https://litellm.i3technologies.co.ke"
)

# Chat completion
response = client.chat.completions.create(
    model="qwen-fast",
    messages=[
        {"role": "system", "content": "You are a helpful assistant."},
        {"role": "user", "content": "What is the capital of Kenya?"}
    ]
)
print(response.choices[0].message.content)

# Text embedding (for RAG)
embed_resp = client.embeddings.create(
    model="embed",
    input="Text to embed for vector search"
)
vector = embed_resp.data[0].embedding

15. Instructor Guide — EvalOS Exam Management Instructors

Creating an Exam

  1. Log in to EvalOS with your instructor credentials.
  2. Go to Instructor Panel → Exams → New Exam.
  3. Fill in: Title, Description, Duration (minutes), Execution Profile (A/B/C/D), Pass Score (%), and Draw Specification.

Draw Specification (JSON)

Controls which questions are randomly drawn per student attempt — preventing answer sharing:

[
  { "topic": "python-fundamentals", "count": 5, "difficulty_min": 1, "difficulty_max": 3 },
  { "topic": "ml-concepts",         "count": 3, "difficulty_min": 2, "difficulty_max": 4 },
  { "topic": "pytorch-practicals",  "count": 2, "difficulty_min": 3, "difficulty_max": 5 }
]

Managing the Question Bank

  1. Go to Question Bank → Add Question.
  2. Choose type: MCQ, Short Answer, or Code.
  3. For Code questions, provide:
    • Stem — the problem description
    • Test cases — input/expected output pairs
    • Test harness — wrapper code injected around the student's submission
    • Bloom level — Recall / Understand / Apply / Analyse / Evaluate / Create
  4. Set is_active = true to include in future draws.

Publishing & Scheduling an Exam

  1. Open the exam and click Publish.
  2. Set Available From and Available Until dates and times.
  3. Assign to a Cohort — students in that cohort will see it on their Dashboard.

Reviewing Anti-Cheat Flags

  1. Go to Instructor Panel → Submissions.
  2. Flagged attempts show a ⚠ icon.
  3. Click to see: anti-cheat event timeline, sandbox execution logs, and MOSS plagiarism score (code questions).
  4. Options: Dismiss the flag, Mark for Review, or Void the Attempt.

Grading

  • Code questions are auto-graded by test case pass/fail.
  • Short-answer and essay questions: open the attempt → enter score and optional comment per question → click Save Grades.
  • Click Publish Results to make scores visible to students.

16. Instructor Guide — AI Lab Cohort Management Instructors

Provisioning a New Cohort

# From the workspace root (PowerShell)
make provision-cohort COHORT=2 STUDENTS="alice,bob,carol,david" GPU_QUOTA=1

This creates: a cohort-2 namespace with ResourceQuotas and NetworkPolicies, per-student RBAC roles, and JupyterHub profiles. Set GPU_QUOTA=0 to disable GPU for the cohort.

Adjusting a Student's Resource Quota

oc patch resourcequota student-alice-quota -n cohort-2 \
  --type=merge \
  -p '{"spec":{"hard":{"limits.nvidia.com/gpu":"2"}}}'

Monitoring Student AI Usage

  1. Navigate to https://langfuse.i3technologies.co.ke.
  2. Go to Traces and filter by user_id (student's Keycloak username).
  3. See every LLM API call: model, prompt, response, token count, cost, and latency.

Stopping a Cohort's Workbenches (Free GPU)

# Scale all single-user servers in a cohort to zero
oc get pods -n cohort-2 -l component=singleuser-server \
  -o name | xargs oc delete -n cohort-2

17. Instructor Guide — OTT Live Broadcasting Instructors

Equipment Required

  • OBS Studio v30+ — free and open source (https://obsproject.com)
  • Stable internet: minimum 6 Mbps upload for 1080p30
  • Optional: dedicated HDMI capture card for external cameras

OBS Setup — RTMP Ingest (Standard)

  1. Open OBS → Settings → Stream.
  2. Set:
    • Service: Custom
    • Server: rtmp://ingest.i3technologies.co.ke:1935/live
    • Stream Key: your stream key (obtain from your admin)
  3. Under Settings → Output:
    • Video Bitrate: 4000 Kbps (1080p30)
    • Audio Bitrate: 128
    • Encoder: x264 or hardware encoder if available
  4. Click OK then Start Streaming.

OBS Setup — SRT Ingest (Lower Latency <2s)

  1. Settings → Stream → Service: Custom
  2. Server: srt://ingest.i3technologies.co.ke:9999?streamid=live/<your-key>
  3. Start streaming as normal.

Recommended OBS Video Settings

SettingValue
Base (Canvas) Resolution1920×1080
Output (Scaled) Resolution1920×1080
FPS30
Keyframe Interval2 seconds

During a Stream

  • Your stream appears at https://stream.i3technologies.co.ke within 3–5 seconds.
  • Viewers can watch in WebRTC (lowest latency) or LL-HLS.
  • The platform automatically creates 4 quality levels: 1080p, 720p, 480p, 240p.

After Your Stream Ends

When you click Stop Streaming in OBS:

  1. OvenMediaEngine automatically triggers the OTT pipeline.
  2. The pipeline transcodes the recording and generates AI subtitles.
  3. The VOD recording appears in Directus CMS within 10–15 minutes.
  4. Students can watch the recorded lecture at https://hls.i3technologies.co.ke.
If the VOD does not appear after 20 minutes, re-trigger the pipeline manually in n8n (see Section 11 — Manual Content Pipeline Trigger).
