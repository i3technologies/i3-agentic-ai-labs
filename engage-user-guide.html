1 — Overview

Engage is i3 Technologies' multi-channel customer engagement platform, enabling organisations to run SMS and WhatsApp campaigns at scale via Africa's Talking (SMS) and WhatsApp Business API (Meta). The platform includes AI-powered message drafting, delivery analytics, and automation flows.

2 — Login & Workspace Setup

  1. Go to https://engage.i3technologies.co.ke and click Sign In.
  2. Authenticate via the i3 SSO portal with your @i3technologies.co.ke credentials.
  3. Select or create a Workspace (e.g. your organisation or department). One workspace = one sender ID / WhatsApp number.
  4. Set your workspace timezone (important for scheduled campaigns) and click Save Settings.

3 — Contact Management

3.1 Importing Contacts

  1. Click Contacts in the sidebar, then Import Contacts.
  2. Download the CSV template. Required columns: phone (format: 2547XXXXXXXX), first_name. Optional: last_name, email, custom attributes.
  3. Upload the CSV. The system validates phone numbers and removes duplicates. A preview of the first 10 rows is shown.
  4. Map CSV columns to Engage fields and click Confirm Import.

3.2 Creating Contact Lists

  1. Go to Contacts → Lists → New List.
  2. Name the list (e.g. "Nairobi Customers Q3") and either manually add contacts or set filter rules for a dynamic list.
  3. Dynamic lists auto-update when contacts match the filter criteria (e.g. county = Nairobi AND last_purchase > 30 days ago).
NoteAll contacts must have opted in to receive communications. Ensure your import file contains only consented contacts in compliance with the Kenya Data Protection Act (2019).

4 — SMS Campaigns

4.1 Creating an SMS Campaign

  1. Go to Campaigns → New Campaign → select SMS.
  2. Enter campaign name, select sender ID, and choose target contact list(s).
  3. Compose your message in the text editor. The character counter shows SMS segments (160 chars = 1 SMS; longer messages are split).
  4. Use {{first_name}}, {{custom_field}} for personalisation. A preview renders with real contact data.
  5. Choose Send Now or Schedule (pick date and time in your workspace timezone).
  6. Review the cost estimate (based on Africa's Talking per-SMS rate) and click Launch Campaign.

4.2 SMS Character Limits

EncodingSingle SMSMulti-part SMS (per part)
GSM-7 (standard)160 characters153 characters
Unicode (Swahili special chars, Arabic)70 characters67 characters
WarningUsing special characters like curly quotes or non-ASCII symbols switches encoding to Unicode, cutting character limits in half. Stick to standard ASCII characters for bulk SMS.

5 — WhatsApp Campaigns

WhatsApp campaigns require pre-approved Message Templates from Meta before bulk sending. The platform manages template submission and approval status.

5.1 Submitting a Template for Approval

  1. Go to WhatsApp → Templates → New Template.
  2. Choose template category: Marketing, Utility, or Authentication.
  3. Write the template body. Use {{1}}, {{2}} for variable placeholders.
  4. Optionally add header (image / document / text) and footer.
  5. Click Submit to Meta. Approval typically takes 24–48 hours.

5.2 Sending a WhatsApp Campaign

  1. Go to Campaigns → New Campaign → select WhatsApp.
  2. Select an approved template, fill in variable values, and choose target list.
  3. Schedule or send immediately, then click Launch.
NoteOnly opt-in contacts who have messaged your WhatsApp number within the last 24 hours can receive free-form messages. All other contacts require approved templates.

6 — Automation & Flows

Automation Flows trigger messages based on contact behaviour or time-based conditions.

TriggerExample Use Case
Contact joins listSend a welcome SMS when a voter registers
Date-basedSend a birthday message 1 day before a contact's birthday field
Webhook eventSend confirmation SMS when an M-Pesa payment is received from PMaaS
No engagementSend a re-engagement WhatsApp after 30 days of silence

Building a Flow

  1. Go to Automation → New Flow.
  2. Select a trigger type and configure its conditions.
  3. Add steps: Send SMS, Send WhatsApp, Wait, Condition branch, or Update contact field.
  4. Toggle the flow to Active to start processing.

9 — Troubleshooting

IssueFix
SMS not deliveredCheck the delivery report for error code. Common codes: 400 = invalid number, 401 = insufficient credits, 500 = carrier error. Verify number format is 2547XXXXXXXX.
WhatsApp template rejectedCommon reasons: promotional language in Utility templates, missing variable formatting. Review Meta's template guidelines and resubmit.
Campaign stuck in "Sending"Large campaigns (>10,000 contacts) process in batches. Allow up to 1 hour. If stuck beyond 2 hours, contact support.
Cannot see contacts after importImport may still be processing. Refresh after 2 minutes. If contacts still missing, check the import error log under Contacts → Import History.
Automation flow not triggeringEnsure the flow status is Active. Check trigger conditions — contact must meet all defined criteria.
