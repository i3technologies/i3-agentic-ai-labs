1. Overview & Purpose

Keycloak (deployed as Red Hat SSO) is the centralised identity and access management (IAM) service for the entire i3 Platform. All 27 applications use Keycloak for authentication via OpenID Connect (OIDC) and OAuth 2.0.

Users log in once at the SSO portal and gain access to all authorised applications without re-entering credentials — this is Single Sign-On (SSO).

FeatureDescription
ProtocolOpenID Connect 1.0 / OAuth 2.0 / SAML 2.0
SSO realmi3 (all platform apps)
Master realmAdmin-only realm for Keycloak configuration
User federationLocal database (LDAP federation available if needed)
MFATOTP (Google Authenticator / Authy) — configurable per role
Token lifespanAccess token: 5 min | Refresh token: 30 min | SSO session: 8 hrs

5. Admin Guide — User Management

Creating a New User (Admin Console)

1
Go to keycloak.i3technologies.co.ke → Log in with admin credentials above.
2
In the top-left dropdown, select realm "i3" (not "master").
3
Left sidebar → Users → Add User.
4
Fill in: Username (required), Email, First Name, Last Name. Set Email Verified = ON. Click Save.
5
Go to Credentials tab → Set Password. Uncheck "Temporary" if you want a permanent password. Click Save Password.
6
Go to Role Mappings tab → assign appropriate roles (see Section 7).

Resetting a User Password (Admin)

1
Realm i3 → Users → find the user → click their username.
2
Credentials tab → Reset Password. Enter new password. Toggle "Temporary" ON to force change at next login.
3
Click Reset Password → Confirm.

Disabling / Deleting a User

  • Disable: Users → click user → Details tab → set Enabled = OFF → Save. The user can no longer log in but their data is retained.
  • Delete: Users → click user → Actions dropdown → Delete. This is irreversible.

Finding a User

# Via Admin API (useful for bulk queries)
# Get token first
TOKEN=$(curl -s -d "username=admin&password=REDACTED-keycloak-admin&grant_type=password&client_id=admin-cli" \
  https://sso.i3technologies.co.ke/auth/realms/master/protocol/openid-connect/token | jq -r .access_token)

# Search users by email
curl -s -H "Authorization: Bearer $TOKEN" \
  "https://sso.i3technologies.co.ke/auth/admin/realms/i3/users?email=user@example.com"

6. Admin Guide — Creating New OIDC Clients

1
Realm i3 → Left sidebar → Clients → Create Client.
2
Set Client type = OpenID Connect, enter Client ID (e.g. my-new-app). Click Next.
3
Authentication flow: enable Standard flow (web apps) and/or Service accounts (M2M). Click Next.
4
Set Root URL and Valid redirect URIs (e.g. https://myapp.i3technologies.co.ke/*). Set Web origins to +. Click Save.
5
Go to Credentials tab → copy the Client Secret. Store it in a Kubernetes secret in your app's namespace.
6
Configure your app with: KEYCLOAK_ISSUER=https://sso.i3technologies.co.ke/auth/realms/i3, KEYCLOAK_CLIENT_ID=my-new-app, KEYCLOAK_CLIENT_SECRET=<secret>.

8. Admin Guide — Operations & Troubleshooting

Check Keycloak Pod Health

$env:KUBECONFIG = "$env:USERPROFILE\.bluemix\plugins\container-service\clusters\i3-platform-da0umukf0anep6valpig-admin\kube-config.yaml"
oc get pods -n i3-auth --no-headers
oc logs keycloak-0 -n i3-auth --tail=30

Restart Keycloak

# Keycloak is deployed as a StatefulSet
oc rollout restart statefulset/keycloak -n i3-auth
oc rollout status statefulset/keycloak -n i3-auth

Export Realm Configuration (Backup)

# Export the i3 realm as a JSON backup
oc exec keycloak-0 -n i3-auth -- /opt/keycloak/bin/kc.sh export \
  --dir /tmp/realm-export --realm i3
oc cp i3-auth/keycloak-0:/tmp/realm-export/i3-realm.json ./i3-realm-backup.json

9. User Guide — Logging In to Any i3 Application

All i3 platform applications share a single login. You only need one username and password.

How to Log In

1
Open any i3 application — e.g. evalos.i3technologies.co.ke
2
Click "Log In" or "Sign In". You will be redirected to the i3 SSO login page at sso.i3technologies.co.ke
3
Enter your username (or email address) and password. Click Sign In.
4
You are automatically redirected back to the application you were trying to use — logged in.
5
Open any other i3 application in the same browser — you are already logged in (SSO). No need to enter your password again.
Session Duration: Your session remains active for 8 hours. After that, you will be asked to log in again.

10. User Guide — Password Reset

Self-Service Reset (if you know your current password)

1
Go to sso.i3technologies.co.ke/auth/realms/i3/account/
2
Log in with your current credentials.
3
Click Account Security → Signing In → Update Password.
4
Enter your current password, then your new password twice. Click Submit.

Forgot Password

1
Go to any i3 application → click Sign In → on the login page click "Forgot Password?"
2
Enter your email address and click Submit.
3
Check your email for a password reset link from noreply@i3technologies.co.ke. Click the link within 30 minutes.
4
Enter and confirm your new password. You are now logged in.
No email received? Check your spam/junk folder. If still not received, contact your IT administrator to reset your password manually.

11. User Guide — Profile Management

Updating Your Profile

1
Go to sso.i3technologies.co.ke/auth/realms/i3/account/
2
Click Personal Info to update your name, email address, and phone number.
3
Click Save. Changes apply immediately across all i3 applications.

Setting Up Two-Factor Authentication (2FA)

1
Account page → Account Security → Signing In → find "Authenticator Application" → click Set up Authenticator Application.
2
Install Google Authenticator or Authy on your phone.
3
Scan the QR code shown on screen with your authenticator app.
4
Enter the 6-digit code from your app to verify. Click Submit.
5
From now on, every login will require both your password and the 6-digit code from your app.

Viewing Your Active Sessions

Account page → Account Security → Device Activity. You can see all active sessions across devices. Click Sign Out All Devices if you suspect unauthorised access.
