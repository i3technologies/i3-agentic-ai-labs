Overview

Platform Overview

EvalOS is i3 Technologies' AI-powered assessment and certification platform. It enables instructors and administrators to design examinations, manage candidate enrolments, run proctored or self-paced assessments, auto-grade responses with an LLM back-end, and issue verifiable digital certificates — all within a single, SSO-authenticated web application.

Admin Guide

1 · What EvalOS Does

EvalOS provides the full assessment lifecycle in one platform:

  • Exam authoring — rich question editor supporting MCQ, short-answer, essay, code, and file-upload question types.
  • Candidate management — bulk enrolment, group/cohort assignment, and scheduling windows.
  • Live proctoring flags — tab-switch detection and webcam snapshot triggers (optional per-exam).
  • AI auto-grading — short-answer and essay responses are scored by Mistral 7B via LiteLLM with a configurable rubric prompt; MCQ is graded instantly on submission.
  • Analytics dashboard — per-exam statistics: score distribution, average, pass rate, per-question difficulty index.
  • Certificate issuance — PDF certificates generated server-side with a verifiable QR code; records written back to SIT Work-Centers via sit-api.
  • RAG question bank — questions are vectorised into ChromaDB enabling semantic search and AI-assisted question generation.

2 · Creating Exams & Assessments

2.1 Access the Exam Builder

1
Sign in — Navigate to https://evalos.i3technologies.co.ke and authenticate with your Keycloak SSO credentials. You must have the evalos-admin or evalos-instructor realm role assigned in Keycloak.
2
Open Admin Dashboard — Click the grid icon (top-right) → Admin Panel. The sidebar shows: Exams, Candidates, Results, Certificates, Settings.
3
New Exam — Click Exams → Create New Exam. The exam builder opens in a two-pane layout: settings on the left, question canvas on the right.

2.2 Configure Exam Settings

4
Basic info — Enter the Exam Title, Description, and optionally a Course Code. These appear on the candidate's exam card and on the issued certificate.
5
Scheduling — Set the Start Date/Time and End Date/Time. Candidates can only access the exam within this window. Enable Allow Late Submission if a grace period is needed.
6
Duration & pass mark — Set the time limit (minutes) and the minimum pass percentage (e.g. 60). EvalOS auto-calculates pass/fail on submission.
7
Grading mode — Choose Auto (AI) for essays/short-answer, Auto (MCQ) for objective questions, or Manual to queue responses for human review. Mixed exams can combine all three.
8
Proctoring — Toggle Enable Proctoring to activate tab-switch events and webcam snapshots. Set the maximum allowed tab-switch count before the exam is auto-submitted.

2.3 Adding Questions

9
Add a question — Click + Add Question on the canvas. Select the type: Multiple Choice, True/False, Short Answer, Essay, Code, File Upload.
10
MCQ — Enter the question stem, add 2–6 answer options, and mark the correct answer(s). Assign a point value per question.
11
Essay / Short Answer (AI grading) — Enter the question and the Model Answer / Rubric field. This rubric text is injected into the LiteLLM prompt when grading. Example rubric: "Award 2 points for mentioning X, 2 for Y, 1 for any mention of Z."
12
Import from question bank — Click Import from Bank to search ChromaDB semantically. Type a topic or keyword; the RAG layer returns the top-N matching questions. Select and import them directly onto the canvas.
13
Save & Publish — Click Save Draft to preserve work, then Publish when ready. Published exams become visible to enrolled candidates at the scheduled start time.
Tip: Question randomisation Enable Shuffle Questions and Shuffle Options per exam to reduce collusion risk. Each candidate then receives questions in a different order.

3 · Managing Candidates

1
Candidates list — Go to Candidates in the sidebar. All users with the evalos-candidate Keycloak role appear here automatically after first login.
2
Bulk enrolment — Click Enrol Candidates → Upload CSV. The CSV must have columns: email, full_name, cohort. The system matches emails to Keycloak users and creates accounts for new ones via the admin API.
3
Assign to exam — Open the target exam → Enrolment tab → Add Candidates. Search by name/email or select an entire cohort. Candidates receive an email notification with the exam link and scheduled time.
4
Cohort groups — Use Candidates → Cohorts → New Cohort to create named groups (e.g. "Batch 2026-Q1"). Assign multiple candidates at once, then enrol the whole cohort to any exam in seconds.
5
Deactivate a candidate — Find the candidate, click ⋯ → Deactivate. This revokes their access to all upcoming exams without deleting historical results.

4 · Viewing Results & Analytics

1
Open Results — Go to Results in the sidebar and select an exam. The overview shows: total attempts, average score, highest/lowest, pass rate %.
2
Individual result — Click a candidate's row to expand their response sheet. MCQ answers are shown with green (correct) or red (incorrect) highlights. AI-graded responses show the LLM score, reasoning excerpt, and the rubric used.
3
Override AI grade — On any AI-graded response, click the pencil icon to manually adjust the score and add a comment. The system logs the override for audit purposes.
4
Analytics charts — The Analytics tab shows: score distribution histogram, per-question discrimination index, and a cohort comparison chart. Export as CSV via the download button.
5
LLM trace inspection — For AI-graded exams, click View LLM Trace on any response to open the Langfuse session. This shows the exact prompt sent, model response, token count, and latency.

5 · Certificate Management

1
Auto-issue — When an exam is configured with Auto-Issue Certificate: ON, EvalOS generates and dispatches PDF certificates automatically upon grading completion for all passing candidates.
2
Manual issue — Go to Certificates → Pending. This lists passing candidates who have not yet received a certificate. Select and click Issue Selected.
3
Certificate template — Under Settings → Certificate Template, upload a branded PDF template (A4 landscape). Placeholders: {{candidate_name}}, {{exam_title}}, {{score}}, {{date}}, {{cert_id}}. The QR code is auto-embedded.
4
Verification URL — Each certificate contains a QR code linking to https://evalos.i3technologies.co.ke/verify/{cert_id}. Anyone can scan to see the candidate's name, exam, score, and issue date — no login required.
5
Revoke a certificate — Open the issued certificate record, click Revoke, and provide a reason. The verification page will then show "Certificate Revoked" with the date.

6 · SIT Work-Center Integration

EvalOS writes assessment outcomes back to the SIT (Student Information & Tracking) Work-Centers via the sit-api bridge service. This keeps EvalOS scores and certificates in sync with the main student record system.

How the bridge works

  • On certificate issuance, EvalOS calls POST /api/sit-bridge/assessment-result on the sit-api service.
  • The payload includes: candidate_email, exam_code, score, pass_fail, cert_id, issued_at.
  • SIT Work-Centers then display the certification record under the student's profile automatically.

Verify bridge connectivity

# Confirm sit-api service is reachable from the evalos pod
oc exec -n i3-evalos deployment/evalos -- \
  curl -sf http://sit-api.i3-sit.svc.cluster.local/health

# View recent bridge call logs
oc logs -n i3-evalos deployment/evalos --tail=100 | grep "sit-bridge"

# Check sit-api bridge pod status
oc get pods -n i3-sit -l app=sit-api
Bridge failure handling If the SIT API is unreachable, EvalOS queues the payload and retries with exponential back-off (max 5 attempts over 30 minutes). Failed payloads appear in Settings → Integration → Pending SIT Sync. You can manually replay them from there.

7 · Zuri AI Coworker

Zuri (zuri.i3technologies.co.ke) is an AI study assistant that runs alongside EvalOS and is powered by the same Mistral 7B model and ChromaDB question bank.

  • Conversational Q&A — Students ask questions in natural language; Zuri retrieves relevant context from the ChromaDB question bank (RAG) and generates a grounded explanation.
  • Practice questions — Zuri can generate on-demand practice questions on any topic, mimicking the style of actual exam questions.
  • Exam hints — If a student is confused about a past result, they can paste the question into Zuri for a detailed worked answer (available only after the exam window closes).
  • Same SSO — Students log into Zuri with the same Keycloak credentials; no separate account needed.

Admin tasks for Zuri

# Check Zuri pod health
oc get pods -n i3-evalos -l app=zuri

# View Zuri logs
oc logs -n i3-evalos deployment/zuri --tail=80

oc rollout restart deployment/zuri -n i3-evalos

# Update ChromaDB with newly authored questions
# (Run the ingest job after publishing a new exam)
oc create job --from=cronjob/chroma-ingest chroma-ingest-manual -n i3-evalos

8.4 Database Backup

# One-off pg_dump of evalos_db (run from the postgres pod)
PGPOD=$(oc get pod -n i3-evalos -l app=postgresql -o jsonpath='{.items[0].metadata.name}')

oc exec -n i3-evalos $PGPOD -- \
  pg_dump -U evalos evalos_db \
  > evalos_db_backup_$(date +%Y%m%d_%H%M).sql

# Verify the dump file size
ls -lh evalos_db_backup_*.sql

# Restore from a backup
oc exec -i -n i3-evalos $PGPOD -- \
  psql -U evalos evalos_db \
  < evalos_db_backup_20260101_0900.sql

8.5 Scaling

# Scale EvalOS to 3 replicas during peak exam periods
oc scale deployment/evalos -n i3-evalos --replicas=3

# Scale back down after the exam window
oc scale deployment/evalos -n i3-evalos --replicas=1

User Guide

1 · Logging In with SSO

EvalOS uses your organisation's Single Sign-On (SSO) system. You do not need a separate EvalOS password — use the same username and password you use for all other i3 platforms.

1
Open the platform — Go to https://evalos.i3technologies.co.ke in your browser. Chrome, Edge, or Firefox are recommended.
2
Click "Sign In" — You will be redirected to the i3 SSO login page at sso.i3technologies.co.ke.
3
Enter your credentials — Type your i3 username (usually your email address) and password, then click Log In.
4
Two-Factor Authentication (if prompted) — If your account has 2FA enabled, enter the one-time code from your authenticator app when prompted.
5
You are redirected back to EvalOS — After successful authentication, you land on your personal dashboard showing your scheduled exams and past results.
First-time login On your very first login, EvalOS may ask you to confirm your profile details (full name, department). Fill these in accurately — they appear on your certificate.

2 · Taking an Exam

1
Find your exam — Your dashboard shows exam cards. Each card displays the exam name, scheduled date/time, duration, and status (Upcoming, Open, Closed). Only exams with status Open can be started.
2
Click "Start Exam" — A confirmation dialog appears showing the exam rules: duration, number of questions, and whether proctoring is active. Read carefully, then click Begin.
3
Allow webcam (if proctored) — If the exam requires proctoring, your browser will ask permission to access your webcam. Click Allow. You cannot proceed without granting access on proctored exams.
4
Read each question carefully — Questions appear one per page or all on one scrollable page, depending on the exam configuration. For MCQ, click your chosen option. For short-answer and essay, type in the text box provided.
5
Use the question navigator — The right-side panel shows a numbered grid of all questions. Green = answered, Grey = unanswered. Click any number to jump to that question.
6
Stay on the exam tab — If proctoring is active, switching to another browser tab triggers a warning. Accumulating more than the allowed number of tab switches will auto-submit your exam.
7
Review before submitting — When you have answered all questions, click Review Answers. This lists every question with your selected answer. Make any final changes.
8
Submit — Click Submit Exam and confirm in the dialog. Once submitted, you cannot make changes. The system records your submission timestamp. The timer auto-submits at zero if you have not done so.
Do not close the browser tab during an exam If you accidentally close the tab, reopen EvalOS and click the exam card — your session and answers are preserved for the duration of the exam window. Do not clear browser cookies mid-exam.

3 · Viewing Your Results

1
Navigate to Results — After submission, you are automatically taken to your result page. You can also access it anytime via Dashboard → My Results.
2
Result summary — The page shows your total score (e.g. 74 / 100), percentage, and pass/fail status highlighted in green or red.
3
Question breakdown — Click View Detailed Results to see each question, your answer, the correct answer, and the points awarded. For AI-graded essay responses, a brief AI feedback comment is shown.
4
Pending AI grading — If your exam included essay questions, the result may show "Grading in progress" for those sections. AI grading typically completes within 2–5 minutes after submission. Refresh the page or wait for an email notification.

4 · Downloading Your Certificate

1
Eligibility — Certificates are issued automatically to candidates who meet or exceed the pass mark. You will receive an email notification when your certificate is ready.
2
Open My Certificates — From your dashboard, click My Certificates in the top navigation bar. All issued certificates are listed with the exam name, date, and score.
3
Download PDF — Click the Download button (↓ icon) next to the certificate. A branded PDF opens in a new tab. Use your browser's print/save function to save a local copy.
4
Verify your certificate — Every certificate contains a unique QR code. Scan it with any QR reader to open the public verification page — no login required. Share this URL with employers or institutions to verify authenticity.
5
Certificate not showing? — If you passed but your certificate is not yet available, it may still be processing (allow up to 15 minutes). If the issue persists after 30 minutes, contact your exam administrator.

5 · Using Zuri AI Study Assistant

Zuri is your AI-powered study companion. Visit https://zuri.i3technologies.co.ke — same SSO login.

1
Log in — Open zuri.i3technologies.co.ke and sign in with your i3 SSO credentials. You will land on the Zuri chat interface.
2
Ask a question — Type any question in the chat box. For example: "Explain the OSI model layers" or "What is the difference between TCP and UDP?" Zuri retrieves relevant material from the question bank and generates a clear explanation.
3
Request practice questions — Type: "Give me 5 practice MCQs on cloud computing". Zuri generates exam-style questions with answers and explanations.
4
Review past exam questions — After an exam window closes, you can paste a question from your result breakdown into Zuri and ask for a worked solution. Zuri explains the reasoning step by step.
5
Study plan — Ask Zuri: "Create a 2-week study plan for my upcoming Networking exam". Zuri drafts a structured plan based on common topics in the question bank for that subject.
Zuri is a study aid, not an exam bypass Zuri does not have access to live exam questions or answers during an open exam window. It is designed to help you learn and prepare, not to give exam answers in real time.

6 · User Troubleshooting

ProblemWhat to Do
The exam loads slowly or shows a spinner for a long time Check your internet connection. Try refreshing the page (F5). If it persists, clear browser cache and cookies for evalos.i3technologies.co.ke, then reload. Use a wired connection or stable Wi-Fi during exams.
"Session Expired" message appears mid-exam Your authentication token has timed out. Click Resume Session on the dialog — you will be re-authenticated silently without losing answers. If that fails, close the tab, re-open EvalOS, and log in again; your answers are auto-saved every 30 seconds.
Cannot submit the exam — button is greyed out Ensure all mandatory questions are answered. Mandatory questions are marked with a red asterisk (*). Check the question navigator for any unanswered grey squares. Once all mandatory questions are completed, the submit button activates.
Webcam permission denied — cannot start proctored exam Click the camera icon in your browser address bar and select Allow for camera access. If it is blocked at the OS level, go to System Settings → Privacy → Camera and enable access for your browser. Reload the page after granting permissions.
My result shows "Grading in progress" even after 30 minutes The AI grading service may be experiencing a delay. Refresh the page. If the status does not change after 1 hour, contact your administrator — they can manually trigger grading or override scores.
Certificate is not available even though I passed Allow up to 15 minutes for auto-issuance. Check your email for a certificate notification. If neither has arrived after 30 minutes, contact the exam administrator and provide your exam name and submission time.
I cannot log in — SSO page shows an error Confirm you are using the correct i3 credentials. If you have forgotten your password, use the Forgot Password link on the SSO login page. If the error persists, contact your IT administrator — your account may need to be re-assigned the evalos-candidate role in Keycloak.
Zuri AI gives incorrect or irrelevant answers Try rephrasing your question with more specific keywords. If the topic is very new and not yet in the question bank, Zuri may have limited context. Report the issue via the thumbs-down button on Zuri's response so the admin team can improve the question bank.
