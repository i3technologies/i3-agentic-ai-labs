Admin Guide

1. Overview & Architecture

EdBridge is the i3 Digital Work-Centers Learning Management System (LMS), deployed as a Bitnami Moodle instance on OpenShift. It hosts all training courses, manages learner enrolments, tracks progress, and delivers online examinations for staff and students across all Work-Center locations.

Tech Stack
LayerTechnologyDetails
ApplicationBitnami MoodleLatest stable release; PHP 8.1+
DatabasePostgreSQLDatabase: edbridge_db, User: edbridge. Credentials in edbridge-secrets.
Container PlatformOpenShiftNamespace: i3-edbridge
File StoragePersistent Volume Claimedbridge-data PVC — 20 GiB. Contains all uploaded course files, backups, and moodledata.
AuthenticationKeycloak OIDCClient ID: i3edbridge on sso.i3technologies.co.ke
Back-channelsit-apiSIT Work-Centers writes enrolment data back to Moodle via sit-api.
IngressOpenShift Routemoodle.i3technologies.co.ke (TLS terminated)
PostgreSQL note: The default Bitnami Moodle ships with MariaDB. This deployment replaces it with PostgreSQL. All database credentials are stored in the edbridge-secrets Secret in the i3-edbridge namespace — never commit them to source control.

3. Accessing Site Administration

1
Navigate to https://moodle.i3technologies.co.ke/login in your browser.
2
Enter username i3admin and the admin password. Click Log in.
3
After login, the top navigation bar shows a Site administration link (only visible to the site admin role). Click it.
4
The Site Administration panel is tabbed: General, Plugins, Security, Appearance, Server, Reports, Development. Key areas:
  • General → Advanced features — enable/disable core features
  • Plugins → Authentication — manage OIDC/SSO plugin
  • Plugins → Enrolments — configure enrolment methods
  • Server → Scheduled tasks — manage cron jobs
  • Reports → Logs — audit trail for all user actions
5
To access the admin panel directly, bookmark: https://moodle.i3technologies.co.ke/admin/

4. Creating Courses

4.1 Course Category Structure

Courses must be organised into categories. Navigate to Site Administration → Courses → Manage courses and categories.

1
Click Create new category. Enter a name (e.g., Digital Literacy), optionally a parent category, and a description.
2
Save. The new category appears in the left-hand category tree.

4.2 Creating a New Course

1
In the desired category, click Create new course.
2
Fill in Course full name, Short name (unique identifier, e.g. DL101), and Course ID number.
3
Set Course format (Topics, Weekly, Single Activity — see §6).
4
Set Start date, End date, and Enrolment key if using self-enrolment.
5
Click Save and display. The course editing view opens.

4.3 Adding Sections and Activities

1
Click Turn editing on (top-right button).
2
Click Edit section name on any topic/week to rename it (e.g., Week 1: Introduction).
3
Within a section, click Add an activity or resource. The activity picker opens.
4
Select the activity type (Lecture notes → File / Page; assessment → Quiz or Assignment; discussion → Forum).
5
Configure the activity settings and click Save and return to course.
6
Repeat for all sections. Use the drag handles to reorder activities.

5. Enrolling Students

5.1 Manual Enrolment

1
Open the course. In the navigation drawer select Participants.
2
Click Enrol users (button, top right).
3
Search by name or email. Select the role (Student). Click Enrol selected users and cohorts.

5.2 Self-Enrolment

1
Go to course Settings → Enrolment methods. Add Self enrolment.
2
Optionally set an Enrolment key to restrict access to authorised learners.
3
Set a maximum enrolment limit and enrolment duration if required. Save.

5.3 Bulk CSV Enrolment

1
Navigate to Site Administration → Courses → Upload users.
2
Prepare a CSV with columns: username, firstname, lastname, email, course1, type1 where type1=1 means Student.
3
Upload the file, review the preview, and click Upload users.

5.4 Keycloak SSO Auto-Provisioning

When a user logs in via Keycloak SSO for the first time, the OpenID Connect plugin automatically creates their Moodle account from the JWT claims (email, given_name, family_name). To auto-enrol them into a course on first login, combine with the Cohort sync enrolment method:

1
Create a Cohort under Site Administration → Users → Cohorts (e.g., Work-Center Students 2026).
2
In Keycloak, map the user's group to a Moodle cohort field via the i3edbridge client mapper.
3
In the course, add Cohort sync enrolment method and select the matching cohort. Users in the cohort are automatically enrolled.

7. Grading & Gradebook Management

7.1 Accessing the Gradebook

1
Inside a course, click Grades in the navigation drawer.
2
The Grader report shows all students × all graded activities. Use View → User report for an individual student's summary.

7.2 Grade Categories and Weights

1
Go to Gradebook setup (Grades → Setup tab).
2
Click Add category (e.g., Assignments 40%, Exams 60%). Set aggregation to Weighted mean of grades.
3
Drag activities into the correct grade category. Set weights. Save.

7.3 Exporting Grades

Go to Grades → Export → Excel spreadsheet / CSV. Select the columns and download. Useful for offline record-keeping and reporting to Work-Center administrators.

8. Setting Up the Quiz / Exam Module

8.1 Creating a Question Bank

1
Navigate to Site Administration → Question bank or within a course go to More → Question bank.
2
Click Add a new question. Select question type: Multiple choice, True/False, Short answer, Matching, Calculated, or Essay.
3
Fill in question text, answer options, feedback, and marks. Save.
4
Organise questions into categories in the question bank for easy reuse across courses.

8.2 Configuring the Quiz Activity

1
Add a Quiz activity to the course. In the settings form:
  • Timing: Open / close dates, time limit (e.g., 90 minutes), grace period.
  • Attempts: Number of allowed attempts (set 1 for formal exams).
  • Grading: Grading method — Highest grade, Average, First, or Last attempt.
  • Layout: Questions per page, shuffling.
  • Question behaviour: Deferred feedback (results shown only after submission) for exams.
  • Review options: What students see after attempt — during, immediately after, later. For exams, restrict post-attempt review until after all students have sat.
  • Security: Enable Browser security — full-screen pop-up or integrate Safe Exam Browser if required.
2
Click Save and display. Then click Edit quiz to add questions from the question bank.
3
Use Add → from question bank or Add → a random question (randomly drawn from a category — recommended for randomised exams).
4
Set per-question marks. The total quiz mark is automatically calculated. Click Save.

9. Moodle Certificates Plugin

The Custom Certificate plugin (mod_customcert) allows admins to design and automatically issue PDF certificates on course completion.

9.1 Designing a Certificate Template

1
Go to Site Administration → Plugins → Activity modules → Custom certificate → Manage templates.
2
Click Create template. Name it (e.g., i3 Course Completion Certificate). Set page size (A4 Landscape recommended).
3
Add elements using the visual editor: Text (static), User field (learner name), Course name, Date completed, Grade, QR code, Image (for logo/signature).
4
Position and style each element. Preview using Preview certificate. Save.

9.2 Adding Certificate to a Course

1
In the course, Add an activity → Custom certificate.
2
Select the template created above. Set Required minutes in course and Grade required thresholds if applicable.
3
Use Completion conditions to make the certificate available only after the student has completed all required activities.
4
Issued certificates are viewable under Site Administration → Reports → Custom certificate → Issued certificates.

10. SSO Configuration — Keycloak OIDC

EdBridge uses the OpenID Connect authentication plugin (auth_oidc) to delegate login to Keycloak.

10.1 Plugin Configuration

1
Navigate to Site Administration → Plugins → Authentication → Manage authentication.
2
Enable OpenID Connect. Click the settings gear.
3
Set the following values:
FieldValue
Provider Namei3 SSO
Client IDi3edbridge
Client Secret(from edbridge-secrets key oidc-secret)
Authorization Endpointhttps://sso.i3technologies.co.ke/realms/i3/protocol/openid-connect/auth
Token Endpointhttps://sso.i3technologies.co.ke/realms/i3/protocol/openid-connect/token
Userinfo Endpointhttps://sso.i3technologies.co.ke/realms/i3/protocol/openid-connect/userinfo
Redirect URIhttps://moodle.i3technologies.co.ke/auth/oidc/
Scopesopenid email profile
Username mappingemail claim → Moodle username
4
Enable Prevent account creation when authenticating = No (allow auto-provisioning).
5
Save. Test by logging out and clicking the i3 SSO button on the Moodle login page.

10.2 Keycloak Client Settings (i3edbridge)

In Keycloak (admin console at sso.i3technologies.co.ke), the i3edbridge client should be configured as:

  • Client Protocol: openid-connect
  • Access Type: confidential
  • Valid Redirect URIs: https://moodle.i3technologies.co.ke/auth/oidc/*
  • Web Origins: https://moodle.i3technologies.co.ke
  • Mappers: email, given_name, family_name, groups (for cohort mapping)

11. Scheduled Tasks & Cron

Moodle relies on a cron process running inside the pod. The Bitnami image runs it automatically. You can verify and manage tasks via the UI or CLI.

11.1 Viewing Tasks in the UI

Go to Site Administration → Server → Scheduled tasks. Each task shows its next run time, last run time, and status.

11.2 Key Scheduled Tasks

TaskDefault SchedulePurpose
Main cronEvery 1 minuteProcesses all queued Moodle tasks
Automated backupsDaily at 02:00Backs up course data to edbridge-data PVC
Log table cleanupDaily at 04:00Removes old log entries to keep DB lean
Grade cleanupDailyRecalculates grade aggregations
Session cleanupEvery hourClears expired sessions from DB
Certificate issuanceEvery 5 minutesGenerates pending PDF certificates

11.3 Triggering Cron Manually

oc exec -n i3-edbridge edbridge-6d4bff754c-bpvlk -- php /opt/bitnami/moodle/admin/cli/cron.php

Or trigger a specific task:

oc exec -n i3-edbridge edbridge-6d4bff754c-bpvlk -- \
  php /opt/bitnami/moodle/admin/cli/scheduled_task.php \
  --execute='\core\task\automated_backup_task'

12. File Management & Backup

12.1 edbridge-data PVC

All Moodle file uploads (course files, backups, profile pictures, certificate PDFs) reside on the edbridge-data PVC mounted at /bitnami/moodle inside the pod.

# Check PVC usage
oc exec -n i3-edbridge edbridge-6d4bff754c-bpvlk -- df -h /bitnami/moodle

# List backup directory
oc exec -n i3-edbridge edbridge-6d4bff754c-bpvlk -- ls -lh /bitnami/moodle/backups/

12.2 Course Backups (MBZ files)

1
In any course, go to More → Backup. Follow the wizard: select included items → confirm → download the .mbz file.
2
To restore: Site Administration → Courses → Restore course. Upload the .mbz file and follow the restore wizard.

12.3 Full Site Backup Strategy

For disaster recovery, combine two strategies:

  1. PVC snapshot — Take an OpenShift VolumeSnapshot of edbridge-data (coordinate with the infrastructure team).
  2. Database dump: 
    oc exec -n i3-edbridge edbridge-6d4bff754c-bpvlk -- \
  pg_dump -U edbridge edbridge_db > edbridge_db_$(date +%Y%m%d).sql

13. Pod Operations (oc Commands)

Pod name may change after a restart. Always fetch the current pod name with oc get pods -n i3-edbridge before running exec commands.

Get current pod name

oc get pods -n i3-edbridge -l app=edbridge

View application logs

oc logs -n i3-edbridge edbridge-6d4bff754c-bpvlk --tail=100 -f

Open a shell in the pod

oc exec -it -n i3-edbridge edbridge-6d4bff754c-bpvlk -- /bin/bash

Restart the pod (rolling restart)

oc rollout restart deployment/edbridge -n i3-edbridge

Check rollout status

oc rollout status deployment/edbridge -n i3-edbridge

Scale down / up (maintenance window)

# Scale down
oc scale deployment/edbridge -n i3-edbridge --replicas=0

# Scale back up
oc scale deployment/edbridge -n i3-edbridge --replicas=1

Check PVC mount and disk usage

oc exec -n i3-edbridge edbridge-6d4bff754c-bpvlk -- df -h

Health / readiness probe check

oc describe pod -n i3-edbridge edbridge-6d4bff754c-bpvlk | grep -A 5 "Readiness\|Liveness"

View events in namespace

oc get events -n i3-edbridge --sort-by='.lastTimestamp'

Retrieve all secrets in namespace

oc get secrets -n i3-edbridge

14. Admin Troubleshooting

SymptomLikely CauseResolution Steps
Login page returns error / can't log in with local account OIDC plugin misconfigured or Keycloak down; admin account locked Try direct login: /login/index.php?authCAS=off. Check Keycloak pod status. Verify OIDC plugin settings (§10). Unlock account via DB: UPDATE mdl_user SET suspended=0,deleted=0 WHERE username='i3admin';
Database connection failed PostgreSQL pod crashed; credentials rotated but not updated in config.php Check oc get pods -n i3-edbridge; verify PostgreSQL pod running. Confirm config.php credentials match edbridge-secrets. Redeploy if needed.
Slow page load / timeout Missing opcode cache; low PHP memory; DB running slow queries Enable OPcache in PHP config. Increase memory_limit in php.ini. Run EXPLAIN ANALYZE on slow queries in PostgreSQL. Check pod resource limits: oc describe pod ... | grep -A 3 Limits.
Cron not running / tasks overdue Pod restart killed cron; cron lock stuck in DB Run cron manually (§11.3). Check for stuck locks: SELECT * FROM mdl_task_scheduled WHERE nextruntime < EXTRACT(EPOCH FROM NOW())-3600;. Clear with: UPDATE mdl_task_scheduled SET blocking=0;
File upload errors PVC nearing 20 GiB limit; PHP upload_max_filesize too low Check disk usage (§13). Delete old backup MBZ files. Increase PVC via storage team. Edit PHP settings in Moodle admin: Site Administration → Security → Site security settings → Maximum uploaded file size.
SSO redirect loop Keycloak redirect URI mismatch; stale Moodle session cookie Verify Valid Redirect URIs in Keycloak i3edbridge client includes https://moodle.i3technologies.co.ke/auth/oidc/*. Clear browser cookies. Check Moodle $CFG->wwwroot in config.php matches the actual URL exactly.
Certificates not generating Certificate task not running; completion criteria not met Run cron manually. Check task log: Site Administration → Reports → Task logs. Verify course completion criteria are enabled and student meets them.
User Guide

15. Logging In

Access EdBridge using your i3 Digital Work-Centers account through Single Sign-On (SSO). You do not need a separate password — use the same credentials you use for all i3 systems.

1
Open your browser and go to https://moodle.i3technologies.co.ke.
2
On the login page, click the i3 SSO button (blue button). Do not type a username and password into the local fields unless specifically instructed.
3
You are redirected to sso.i3technologies.co.ke. Enter your i3 username and password.
4
Click Sign In. You will be automatically redirected back to Moodle and logged in.
5
If this is your first login, your Moodle account is created automatically from your i3 profile. No further action is needed.
Tip: Bookmark https://moodle.i3technologies.co.ke for quick access. Your session stays active for 2 hours of inactivity.

16. Navigating the Dashboard & Finding Your Courses

1
After login, you land on the Dashboard. It shows:
  • My courses — all courses you are enrolled in
  • Timeline — upcoming assignment and quiz deadlines
  • Recently accessed courses — your recent learning activity
2
To find a specific course, use the search bar at the top of the page, or click My courses in the left navigation drawer.
3
To browse all available courses, click Site home (home icon) or Course catalogue in the navigation drawer.
4
Click any course card to open it. If you are not yet enrolled, you will see an enrolment button or be prompted for an enrolment key (if applicable).
5
To return to the Dashboard at any time, click the grid icon or your institution name in the top navigation.

17. Accessing Course Materials

1
Open your course. The course page is divided into sections (topics or weeks). Each section contains activities and resources.
2
Click on a resource name to open it:
  • PDF / Document: Opens inline in the browser or downloads depending on the instructor's settings.
  • Video / Presentation: Plays directly in the browser using the embedded media player.
  • External link / URL: Opens in a new tab.
  • SCORM module: Launches the interactive e-learning module — allow pop-ups for this site if prompted.
3
Use the breadcrumb trail at the top (e.g., Dashboard › My courses › DL101 › Week 1) to navigate back to the course.
4
Some resources are hidden until you complete earlier activities. If an item appears greyed out, check the completion requirement shown beneath it.

18. Submitting Assignments

1
Navigate to the assignment in your course. Click the assignment title to open it.
2
Read the assignment brief and note the due date and submission type (file upload, online text, or both).
3
Click Add submission.
4
For file submission: drag and drop your file(s) into the upload area, or click the file icon to browse. Supported types and maximum size are shown above the upload area.
5
For online text: type or paste your work into the text editor. You can use the toolbar to format your text, add images, and paste from Word (use the Paste from Word icon to preserve formatting).
6
Click Save changes. Your submission status changes to Submitted for grading. You will receive a confirmation email.
7
If the assignment allows editing before the due date, click Edit submission to update your work.
Important: Do not close the browser while uploading large files. If the upload bar stalls, check your internet connection and try again. Submissions after the due date may be accepted but marked as Late.

19. Taking a Quiz or Exam

1
Navigate to the quiz in your course. Click the quiz title. You will see the quiz description, time limit, number of attempts allowed, and open/close dates.
2
Click Attempt quiz. A confirmation dialog appears — read it carefully (especially the time limit).
3
Click Start attempt. The timer begins immediately in the top-right corner.
4
Answer each question. Use the question navigation panel (right side or bottom) to jump to any question. Flagged questions are highlighted — click the flag icon on a question to mark it for review.
5
Click Next page to advance through multi-page quizzes. Your answers are auto-saved as you go — a network interruption will not lose answered questions.
6
When finished, scroll to the bottom and click Finish attempt. Review the summary page showing answered / unanswered questions.
7
Click Submit all and finish. A final confirmation dialog appears. Click Submit all and finish again to confirm.
8
Your results page appears (if the instructor has enabled immediate feedback). Your grade is recorded in the gradebook automatically.
Time warning: When 5 minutes remain, a red timer warning appears. At zero, the attempt is automatically submitted with whatever answers you have provided. Do not rely on this — aim to finish early.

20. Checking Your Grades

1
While inside a course, click Grades in the left navigation drawer.
2
The User report opens, showing all graded items, your score, the maximum score, and any feedback from your instructor.
3
To view feedback on a specific assignment, click the assignment name in the grade report — it opens the submission with inline feedback and comments.
4
To see grades across all your courses, go to your Profile → Grades overview (click your name/avatar in the top-right → Profile → Grades overview).
5
Grades are usually updated within 7 days of submission. If a grade is missing after that, contact your instructor via the course forum or messaging.

21. Using the Course Forum & Discussion Board

1
In your course, find the Forum activity (usually in the first section as Announcements or a dedicated discussion section). Click it.
2
To read an existing thread, click its title. Replies are nested below the original post.
3
To start a new discussion thread, click Add a new discussion topic. Enter a subject and your message. You can attach files using the attachment area.
4
To reply to an existing post, click Reply under that post. Type your response and click Post to forum.
5
Subscriptions: By default, you receive email notifications for replies in threads you participate in. To manage subscriptions, click Subscribe to this forum (to get all posts) or Unsubscribe to stop receiving emails.
6
The Announcements forum (if present) is instructor-only for posting — students can read but cannot reply. Check it regularly for important course updates.
Netiquette reminder: Keep discussions respectful and on topic. Posts are visible to all enrolled students. Contact your instructor privately for personal matters.

22. Downloading Your Certificate of Completion

1
After completing all required course activities (as defined by the completion criteria), a Certificate activity will become available in the course. Click it.
2
Click Get your certificate (or Download certificate). A PDF certificate opens or downloads to your device.
3
The certificate contains your full name, course name, completion date, and a unique QR code for verification. Save a copy for your records.
4
To retrieve a previously issued certificate, go to the same Certificate activity in the course — it always shows your latest issued certificate.
5
If the certificate activity is not visible or the download button is greyed out, not all completion criteria have been met. Check the course progress by going to My courses → [Course name] → Progress.

23. User Troubleshooting

ProblemWhat to Try
Can't log in / stuck at SSO page
  1. Clear your browser cache and cookies, then try again.
  2. Try an incognito / private browser window.
  3. Ensure you are using your correct i3 username and password at sso.i3technologies.co.ke.
  4. If your account is locked, contact the i3 helpdesk — they can unlock it in Keycloak.
Course not visible in My Courses
  1. Check that the course has started — courses with a future start date may be hidden.
  2. Confirm you are enrolled: go to Site home and search for the course name. If it shows but has an Enrol button, you need to self-enrol or ask your instructor to enrol you.
  3. Ask your instructor or admin to verify your enrolment.
Video won't play / buffering
  1. Check your internet connection speed (minimum 2 Mbps recommended for HD video).
  2. Try a different browser (Chrome or Firefox recommended). Disable browser extensions that may block media.
  3. If using a SCORM module, ensure pop-ups are allowed for moodle.i3technologies.co.ke.
  4. Try downloading the video if the instructor has enabled the download option.
Assignment submission error
  1. Check the file size limit shown on the submission page. Compress or split large files.
  2. Ensure the file type is allowed (e.g., PDF, DOCX — not EXE or ZIP unless specified).
  3. Try a different browser. Disable VPN if active, as it can cause upload timeouts.
  4. If the due date has passed and submission is blocked, contact your instructor immediately to request an extension.
Quiz timer ran out before I finished The quiz is automatically submitted with your answers at time expiry — your partial answers are saved. Contact your instructor to explain and request an additional attempt if the circumstances warrant it. Admins can grant extra attempts per-student in the quiz settings.
Certificate not available after course completion
  1. Check that all required activities are marked as complete (green tick). Some activities require a minimum grade.
  2. Wait up to 10 minutes — certificate generation runs every 5 minutes via cron.
  3. Reload the course page. If still unavailable, contact your instructor or the Moodle admin.
Need further help? Contact the i3 helpdesk via the Work-Center portal or email your course instructor through the Moodle messaging system (click the instructor's name → Message).
