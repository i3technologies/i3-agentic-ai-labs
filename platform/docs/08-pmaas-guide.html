A2 — User Onboarding — Creating Client Accounts in Keycloak

All PMaaS users authenticate via Keycloak SSO. Client accounts must be created in the i3 realm and assigned the i3-client role.

Steps to Create a New Client Account

  1. Log in to the Keycloak Admin Console. Navigate to Realm: i3 → Users → Add User.

  2. Fill in: Username (email preferred), Email, First Name, Last Name. Set Email Verified: ON. Click Save.

  3. Go to the Credentials tab → Set Password. Provide a temporary password and toggle Temporary: ON so the user is prompted to change it on first login. Click Set Password.

  4. Go to the Role Mappings tab → Client Roles → select pmaas-web. Add the role i3-client. This grants access to the PMaaS application.

  5. Optional — for admin access within PMaaS, also assign i3-admin role on the same client.

  6. Notify the user of their login URL: https://pmaas.i3technologies.co.ke and their temporary password.

ℹ Multi-tenancy Note Each client organisation should be set up as a Keycloak Group (e.g. nairobi-county, ngo-xyz). Assign users to the group so PMaaS can scope project visibility by organisation.

Disabling or Removing a User

  1. In Keycloak Users list, find the user and click their username.

  2. To disable: set Enabled: OFF and Save. The user loses access immediately — no need to delete.

  3. To permanently delete: click Delete at the bottom of the user detail page.

A3 — Project / Program Setup

PMaaS supports a two-level hierarchy: Programs (top-level strategic containers) and Projects (deliverable units within a program). For county clients, Programs map to strategic pillars (e.g., Health, Agriculture); for NGOs they map to donor-funded programmes.

Creating a Program

  1. Log in as an admin user → navigate to Programs in the left sidebar.

  2. Click New Program. Fill in: Program Name, Description, Start Date, End Date, Client Organisation (select from dropdown), and Program Manager.

  3. Under Program Type select: County Government, NGO, or Corporate. This controls which module features are visible to client users.

  4. Save. The program appears in the client organisation's workspace.

Creating a Project within a Program

  1. Open the Program → click + Add Project.

  2. Enter: Project Name, Objective, Budget (if applicable), Ward/Location (for county clients — pulled from FORD-Asili API), and Assigned Team Lead.

  3. Set Status: Planning → Active → Completed → Closed.

  4. Click Save Project. The project is now visible to all team members assigned to it.

A4 — Campaign Management Workflow

The Campaign module is primarily used by county governments and corporates for structured communication and mobilisation campaigns.

Creating a Campaign

  1. Navigate to Campaigns → New Campaign.

  2. Enter: Campaign Name, linked Project, Start/End dates, Target Audience, and Geographic Scope (ward or county-level).

  3. Click Generate AI Plan — this calls Dawa AI at http://campaign-agent.i3-pmaas.svc.cluster.local:8080/plan to generate a structured campaign plan with milestones, resource recommendations, and risk flags.

  4. Review the AI plan. Accept, modify, or regenerate individual sections as needed.

  5. Click Activate Campaign. This triggers Brevo email notifications to all assigned team members.

A5 — Dawa AI Coworker

Dawa AI (dawa.i3technologies.co.ke) is the intelligent coworker embedded in PMaaS. It is a FastAPI-based Python agent using LiteLLM for LLM inference and ChromaDB for retrieval-augmented generation (RAG) over project documents.

Dawa AI Capabilities

  • AI campaign plan generation from project brief inputs
  • Progress monitoring — automatic daily summaries of overdue tasks
  • Risk flagging — highlights blocked or at-risk milestones
  • Grant narrative drafting for NGO grant applications
  • Budget variance analysis with natural-language commentary
  • RAG-powered Q&A over uploaded project documents (reports, SOPs, proposal PDFs)

A7 — FORD-Asili Integration

PMaaS serves as the front-end platform for the FORD 2027 ward-first strategy, managed by FORD-Asili. The integration pulls live ward and constituency data from the ford-api service running in the i3-ford namespace.

How It Works

  1. When a user creates a project or campaign, PMaaS calls ford-api to populate the ward/constituency selector with live Kenya geographic data (47 counties → constituencies → wards).

  2. Projects tagged with a ward are visible on the FORD-Asili ward-level heatmap dashboard.

  3. Field agents assigned to a ward project receive location-aware task lists through their PMaaS dashboard.

  4. Dawa AI can generate ward-specific reports showing coverage, task completion rates, and pending activities per ward.

API Endpoint (internal)

# ford-api service (i3-ford namespace)
http://ford-api.i3-ford.svc.cluster.local/api/v1/wards
http://ford-api.i3-ford.svc.cluster.local/api/v1/constituencies
http://ford-api.i3-ford.svc.cluster.local/api/v1/counties
ℹ Configuration The FORD API base URL is stored in pmaas-secrets as FORD_API_URL. If the ford-api service is relocated, update this secret and rollout restart pmaas-web.

A8 — Database Setup — Fixing the pmaas_db Password

🚨 ACTION REQUIRED — Database Password Not Set The pmaas_db database user password is currently set to the placeholder value REPLACE in the pmaas-secrets Kubernetes Secret. The application cannot connect to the database until this is fixed. Complete the steps below before going live with any client.

Step-by-Step: Set the Database Password

  1. Connect to PostgreSQL as the superuser (from any pod with psql access or the postgres pod itself):

    oc exec -it -n i3-infra deploy/postgresql -- psql -U i3admin -d postgres

  2. Set the pmaas role password inside the psql session:

    ALTER ROLE pmaas WITH PASSWORD 'new-secure-password';
\q

  3. Base64-encode the new DATABASE_URL (substitute your actual password and host):

    echo -n "postgresql://pmaas:new-secure-password@pgbouncer.i3-infra.svc.cluster.local:5432/pmaas_db" \
  | base64

  4. Patch the Kubernetes secret with the base64 value from step 3:

    oc patch secret pmaas-secrets -n i3-pmaas --type=merge \
  -p '{"data":{"DATABASE_URL":"<base64-encoded-url-here>"}}'

  5. Rollout restart the deployment to pick up the new secret:

    oc rollout restart deployment/pmaas-web -n i3-pmaas
oc rollout status  deployment/pmaas-web -n i3-pmaas

  6. Verify connectivity — check the pod logs for a successful DB connection message:

    oc logs -n i3-pmaas -l app=pmaas-web --tail=50 | grep -i "database\|prisma\|pool"
✔ Success Indicator The pmaas-web pod logs should show Database connected or similar Prisma pool message. The PMaaS login page should load without a 500 error.

User Guide

U1 — Logging In with SSO

PMaaS uses Single Sign-On (SSO) via Keycloak. You do not need a separate PMaaS password — your i3 platform credentials work across all i3 services.

  1. Open your browser and navigate to https://pmaas.i3technologies.co.ke.

  2. You will be redirected to the i3 login page. Enter your username (usually your work email) and password.

  3. If it is your first login, you will be prompted to set a new password. Choose a strong password (minimum 12 characters).

  4. After authentication you are redirected back to the PMaaS dashboard.

  5. To log out, click your name/avatar in the top-right corner → Sign Out. This logs you out of all i3 SSO-connected services.

ℹ Forgot Password? Click Forgot Password on the login page and enter your email. A reset link will be sent to you. If you do not receive it within 5 minutes, contact your organisation's PMaaS administrator.

U2 — Dashboard Overview

After logging in, the PMaaS Dashboard gives you a real-time summary of your workspace. The layout depends on your role:

WidgetDescriptionVisible to

Dawa AI Feed AI-generated daily digest: progress summaries and alerts Project Managers

Use the left sidebar to navigate between modules: Programs, Projects, Campaigns, Grants, Reports, and Settings.

U3 — Creating a New Project

You need the Project Manager or Admin role within your organisation to create projects.

  1. In the left sidebar, click Projects → + New Project (top right button).

  2. Select the Program this project belongs to from the dropdown. If no program exists, contact your admin to create one first.

  3. Fill in the project details:
    • Project Name — clear, descriptive name
    • Objective — one-sentence goal statement
    • Start Date & End Date
    • Budget (optional — required for grant-linked projects)
    • Location / Ward (county users — select from the ward picker)

  4. Under Team Lead, search and select the person responsible for delivery.

  5. Set the initial Status to Planning.

  6. Click Create Project. You will be taken to the new project's detail page.

  7. Optionally, click Ask Dawa AI to get an AI-generated project plan with suggested milestones and tasks based on your objective.

U4 — Adding Team Members & Assigning Tasks

Adding Team Members to a Project

  1. Open the project → go to the Team tab.

  2. Click Add Member. Search by name or email. Only users registered in your organisation appear (contact admin to add new users).

  3. Assign a role for the project: Contributor, Reviewer, or Viewer.

  4. Click Add. The user receives an email notification (via Brevo) that they have been added to the project.

Creating and Assigning Tasks

  1. Within the project, go to the Tasks tab → + Add Task.

  2. Enter: Task Title, Description, Due Date, Priority (Low / Medium / High / Critical), and link to a Milestone if applicable.

  3. In the Assignee field, select a team member from the project team (added in the step above).

  4. Click Save Task. The assignee receives an email notification.

  5. Tasks can be viewed in List, Board (Kanban), or Gantt views using the view toggle at the top of the Tasks tab.

ℹ Bulk Task Import You can import tasks from a CSV file. Click the Import button on the Tasks tab, download the template, fill it in, and re-upload. Dawa AI will automatically suggest priorities and assignees based on task descriptions.

U5 — Tracking Milestones & Progress

Creating Milestones

  1. In the project, go to Milestones → + Add Milestone.

  2. Enter the milestone name, target date, and description. Link related tasks to the milestone.

  3. Save. Milestones appear on the project timeline and the programme-level Gantt chart.

Updating Progress

  1. To update a task, click it in the task list → change the Status: To Do → In Progress → Review → Done.

  2. Add a Progress Note (optional) to log what was done. These notes are visible to the team and are ingested by Dawa AI for reporting.

  3. The project Overall Progress bar (visible on the project card and dashboard) auto-calculates from completed tasks vs total tasks.

  4. For milestone completion: open the milestone and click Mark as Complete. A completion timestamp is recorded and the programme manager is notified.

U6 — Using Dawa AI for Project Insights

Dawa AI is your intelligent project coworker. It is accessible from any project or campaign via the Ask Dawa button or the AI Insights panel.

What You Can Ask Dawa AI

Request typeExample prompts
Progress summary "Summarise progress on Project X this week"
Risk identification "What tasks are most at risk of missing their deadline?"
Plan generation "Generate a 90-day campaign plan for a health outreach in Kibera ward"
Grant narrative "Draft an executive summary for our water sanitation grant proposal"
Budget analysis "Show me the variance between planned and actual spend on Program Y"
Document Q&A "What does our M&E framework say about indicator KPI-3?"

How to Use the AI Chat

  1. Open a project or campaign → click the Ask Dawa button (sparkle icon, bottom-right of the screen).

  2. The AI chat panel opens. Type your question or request in plain English (Swahili is also supported).

  3. Dawa AI responds with insights drawn from your project data and any uploaded documents. Responses include source references where applicable.

  4. To use document Q&A, first upload relevant files (PDF, DOCX) under Project → Files. Dawa AI indexes them within a few minutes.

  5. You can click Insert into Report on any AI response to add it directly to a report draft.

U7 — Generating Reports & Exporting to PDF

  1. Navigate to Reports in the left sidebar → New Report.

  2. Select the Report Type:
    • Project Status Report — overall health, milestone progress, tasks
    • Campaign Summary — campaign reach, activities, outcomes
    • Grant Progress Report — disbursements, activities vs targets, narrative
    • Ward Activity Report — field activities per ward (county clients)

  3. Select the Project or Programme, the reporting period (date range), and the sections to include.

  4. Click Generate with AI to have Dawa AI pre-fill narrative sections based on project data and progress notes. Review and edit as needed.

  5. Click Preview to see the formatted report. Make any final edits.

  6. Click Export to PDF. The PDF is generated and downloaded to your browser.

  7. To share with stakeholders, use Share Report Link to generate a read-only web link (no login required for external viewers).

U8 — Managing Grants & Budgets

ℹ Grant Module Availability The Grants module is available to organisations configured as NGO type. If you do not see the Grants menu item, contact your PMaaS administrator to enable it for your organisation.

Grant Lifecycle

  1. Go to Grants → + New Grant. Enter: Grant Title, Donor Name, Total Award Amount, Currency, Grant Period (start/end), and link to a Programme.

  2. Under Budget, break the grant into budget lines (Activities, Personnel, Equipment, M&E, Overhead). Save the budget.

  3. As activities are implemented, log Expenditures against each budget line. PMaaS automatically calculates variance (planned vs actual spend).

  4. Set Reporting Deadlines — PMaaS sends Brevo email reminders 30 days, 14 days, and 7 days before each deadline.

  5. When a reporting deadline approaches, use the Generate Report button (see U7) to produce a donor-ready grant progress report.

Budget Variance View

Open a grant → Budget tab. The variance table shows each budget line with:

  • Budgeted amount
  • Amount spent to date
  • % utilised
  • Variance (over/under) highlighted in red/green
  • Dawa AI commentary on significant variances (click AI Analysis)
