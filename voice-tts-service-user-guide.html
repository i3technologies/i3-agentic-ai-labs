1. What is the Voice / TTS Service?

The i3 Voice/TTS (Text-to-Speech) service converts written text into spoken audio using the espeak-ng synthesis engine. It is designed for fast, lightweight, multilingual voice generation — ideal for political voice broadcast campaigns, accessible content delivery, and automated voice messaging. No heavy ML dependencies means low latency and high reliability.

2. How to Use the TTS Service

The TTS service is accessed via its REST API. It is designed for integration by developers and campaign automation systems, not a graphical UI. If you need a UI wrapper, your administrator can embed it in your campaign platform.

API Endpoint Summary

MethodEndpointDescription
GET/v1/healthCheck if service is online and espeak-ng is available
POST/v1/ttsConvert text to WAV audio
GET/v1/voicesList all available voice languages and codes

3. Making a Text-to-Speech Request

Step 1 — Get Your API Token

Contact your administrator to obtain your TTS API bearer token (VOICE_API_KEY). This is required for all requests.

Step 2 — Make the Request

Using curl (command line):

curl -X POST https://voice.i3technologies.co.ke/v1/tts \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "text": "Habari! Tunakualika ushiriki katika mkutano wa wapiga kura wa Machakos leo.",
    "language": "sw",
    "rate": 1.0
  }' \
  --output campaign_audio.wav

Using Python:

import requests

response = requests.post(
    "https://voice.i3technologies.co.ke/v1/tts",
    headers={
        "Authorization": "Bearer YOUR_API_TOKEN",
        "Content-Type": "application/json"
    },
    json={
        "text": "Welcome to the i3 platform. Your onboarding plan is ready.",
        "language": "en",
        "rate": 0.9
    }
)

# Save the WAV file
with open("output.wav", "wb") as f:
    f.write(response.content)

print("Audio saved to output.wav")

Step 3 — Play or Distribute the Audio

The returned .wav file can be:

  • Played directly (any media player on Windows, macOS, Linux)
  • Uploaded to a voice broadcast platform (e.g. AfricasTalking, Twilio)
  • Embedded in a web page using an HTML <audio> tag
  • Used as input for PMaaS voice campaign delivery

6. Checking Service Health

curl https://voice.i3technologies.co.ke/v1/health \
  -H "Authorization: Bearer YOUR_API_TOKEN"

A healthy response:

{
  "status": "ok",
  "espeak": "available",
  "version": "1.0"
}

If espeak shows "unavailable", contact your administrator immediately — the espeak-ng engine may need to be reinstalled in the container.

7. PMaaS Integration

If you are a PMaaS user and have requested a voice script from the Content Generator, the generated script text can be passed directly to the TTS service to produce broadcast-ready audio:

  1. In PMaaS, generate a voice script for your target ward and audience.
  2. Review and approve the script content.
  3. Copy the approved script text.
  4. Submit to the TTS API with "language": "sw" (or appropriate language).
  5. Download the WAV file.
  6. Upload to your voice broadcast provider (e.g. AfricasTalking IVR).
Best Practice for Voice Broadcasts: Keep scripts under 60 seconds of audio (~150 words). Test playback at normal speed before distributing. Use rate: 0.9 for clearer, more professional-sounding recordings.

8. Best Practices for Text Input

  • Use proper punctuation — commas and full stops create natural pauses in speech.
  • Avoid acronyms (write "Kenya Revenue Authority" instead of "KRA") for better pronunciation.
  • Numbers: write out short numbers in words for cleaner speech ("fifty" not "50") in broadcast scripts.
  • Do not exceed 5,000 characters per request — split long content into multiple requests.
  • For Swahili content, use standard Kiswahili spelling for best pronunciation quality.
