Hard Constraint Compliance Review

✅ HC-4 — Tenant Isolation
All API routes call setTenantContext(client, tenantId) before queries. Default tenant UUID used when session has no tenant. Exception: Leaderboard page — raw pool query without tenant context (flagged above).
✅ HC-6 — No Raw NID On-Chain
Device fingerprint explicitly noted as pseudonym (not NID/phone). Candidate emails stored directly in certificates — acceptable for a credential system. No raw Kenyan NID observed anywhere in EvalOS.
✅ HC-7 — Auth Bypass Gate
No DEV_BYPASS_AUTH=true found in any EvalOS file. All routes enforce getServerSession(authOptions) with 401 on missing session.
✅ HC-3 — Autonomy Ceiling
All AI agents (Study Coach, Interview Evaluator, Code Reviewer) are L1: propose-only with no state-mutating authority beyond persisting scored results. Human admins adjudicate integrity flags.
✅ HC-5 — Bounded Execution
LiteLLM gateway is the sole approved inference path. No direct model SDK calls. External calls (n8n, admissions) are all best-effort, non-blocking side-effects with no authority to modify core state.
✅ DB Connection Safety
All database calls use pool.connect() with client.release() in finally block. No asyncpg.connect()-equivalent direct calls. Pool acquired once per request.

Overall Verdict

✅ TypeScript compilation: 0 errors across the entire platform/evalos/web project (tsc --noEmit exits 0).
✅ Core exam flow end-to-end (start → answer → submit → grade → results → certificate) is fully implemented and logically correct. SAGA pattern handles grading-service failure with retry path.
✅ All AI features (Study Coach, Interview Evaluator, Code Review) route exclusively through the LiteLLM gateway with Langfuse observability and proper error propagation.
⚠️ HC-4 Leaderboard gap: getLeaderboard() lacks tenant scoping — all-tenant data exposed to any authenticated user. Fix: use pool.connect() + setTenantContext() with session tenant. Severity: Medium.
⚠️ Study Coach timeout margin: maxDuration=115 s is only 5 s above the 110 s LLM AbortSignal. Langfuse trace + DB write overhead could cause edge-function kills. Raise maxDuration to 120 s. Severity: Low.
⚠️ CSV export pagination: Hard-coded LIMIT 5000 may truncate large cohort exports. Add date-range filtering for completeness at scale. Severity: Low.
⚠️ Sandbox dependency: Coding Labs require the sandbox daemon pod running in the cluster. No dev-mode fallback (e.g., local Node eval) exists — labs fail silently outside cluster. Severity: Low — expected infrastructure dependency.
