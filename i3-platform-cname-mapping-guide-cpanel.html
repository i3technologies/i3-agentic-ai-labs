Before you startLog in to cPanel → Domains → Zone Editor → click Manage next to i3technologies.co.ke. All records below are CNAME type unless otherwise marked. TTL = 300 (5 minutes) during initial setup; increase to 3600 after confirming.

Step-by-Step: Adding a CNAME in cPanel

  1. In Zone Editor click + Add Record.
  2. Set Type to CNAME.
  3. Enter the Name (subdomain only — e.g. evalos) in the Name field.
  4. Paste the CNAME Target value in the Record field. Ensure it ends with a dot (.) or cPanel will append the root domain — remove the trailing dot if cPanel does not accept it.
  5. Set TTL to 300 and click Save Record.
  6. Repeat for each row in the tables below.
  7. After all records are saved, verify with: nslookup evalos.i3technologies.co.ke
Important — Trailing dotSome cPanel versions require the trailing dot on CNAME targets (router-default.apps....cloud.); others strip it automatically. If you see a validation error, remove the trailing dot and retry.
