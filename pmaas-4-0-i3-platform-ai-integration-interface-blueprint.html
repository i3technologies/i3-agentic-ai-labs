🌐 Part 3 — Adding KIMI K3, GLM & Qwen to the Model Gateway

🧠 Why These Models Matter for PMaaS + i3 Platform KIMI K3 (Moonshot AI), GLM-4 (Zhipu AI), and Qwen 2.5 (Alibaba) are world-class open-weight models with exceptional multilingual performance — critical for Swahili, Arabic, and African language support that IBM Granite does not cover as well. All three can be added through the existing LiteLLM gateway with zero architectural changes.

🖥️ Part 4 — AI Interface Design: All Surfaces

📐 The i3 Interface Strategy The platform needs 4 distinct interface surfaces, each with a different persona and purpose — from a public chatbot to a private co-worker assistant. All share the same LiteLLM backend and Keycloak authentication.
💬 Surface 1 — i3 AI Chat (Public Conversational Interface)

A streaming, multi-turn conversational interface. The public face of i3's AI. Used by students, admissions prospects, and voters (PMaaS).

FeatureDetail
Chat personasAdmissions Bot · Student Tutor · Policy Advisor (PMaaS) · Governance Bot (PMaaS)
InputText + file upload (PDF, DOCX for RAG) + voice input (browser Speech API → STT)
OutputStreaming text tokens + rich markdown + code blocks + citations (RAG source + page)
LanguagesEnglish, Swahili, Sheng (route to Qwen/GLM for non-English)
BackendFastAPI WebSocket → LiteLLM → Qwen/GLM/Granite based on detected language
Session memoryLast 20 turns in Redis; long-term user history in PostgreSQL
DeployNext.js frontend at chat.i3technologies.co.ke (new Route)

Innovative Features to Add:

  • Language auto-detect: if Swahili detected → switch to Qwen2.5-7B automatically
  • Voice input: browser mic → Whisper STT → text query → voice output TTS (PMaaS voice clone)
  • Reasoning trace toggle: user can click "Show thinking" to see chain-of-thought steps
  • Persona switcher: user selects "Tutor / Policy Advisor / Code Assistant" — adjusts system prompt + model
  • Source citations: every RAG answer shows document title, page, and excerpt inline
💻 Surface 2 — i3 AI Coding Assistant (Developer Interface)

A VS Code / JupyterHub integrated coding assistant. Serves AI Lab students, platform developers, and EvalOS exam support.

FeatureDetail
InterfaceVS Code extension (Language Server Protocol) + JupyterHub cell magic (%%ai)
Primary modelQwen2.5-Coder-32B (best open-source coding model) + DeepSeek-Coder-V2 as fallback
CapabilitiesCode completion, explain code, refactor, generate tests, debug stack traces, generate docstrings
ContextSends open file + visible code range + error message to model; returns inline diff or explanation
EvalOS integrationStudents click "Hint" in EvalOS → sends current code + failing test to Qwen-Coder → returns hint (not solution)
SecurityCode never leaves the cluster — Qwen/DeepSeek run on-prem via Ollama
API endpointPOST /v1/code/complete on LiteLLM — maps to qwen25-coder alias

Innovative Features:

  • Smart hint system: 3 levels — conceptual hint → pseudocode → worked example (each costs 1 "hint credit")
  • Code review agent: submit PR / notebook → AI reviews for bugs, style, and efficiency
  • AI-generated test cases: given a function signature → generate 10 edge-case tests automatically
  • Plagiarism + MOSS integration: check student code similarity via EvalOS MOSS connector

Co-Worker Interface Design:

  • Single pane sidebar: always-on panel accessible from any app (like Copilot sidebar in Office 365)
  • Context awareness: Co-Worker knows what page/app you are on — if in Directus CMS, offers "help write this content"; if in Grafana, offers "explain this spike"
  • Memory: remembers your preferences, writing style, common queries, and past work within your session
  • Action confirmation: before writing to any external system (CRM, calendar, email send), shows a confirmation card — never acts autonomously on sensitive operations
  • Audit trail: every Co-Worker action logged to Langfuse — who asked what, what model answered, what action was taken
  • Deploy: coworker.i3technologies.co.ke — React app + persistent WebSocket

💡 Part 5 — Innovative Ideas to Consider

🎙️ Universal Voice Layer
Every i3 interface gets a voice toggle. Chat → speak your question, hear the answer. Co-Worker → dictate documents. EvalOS → read questions aloud. PMaaS → full TTS on all messages. Backend: Whisper STT (on-cluster) + ElevenLabs/Watson TTS out.
🌍 African Language Expansion
Qwen2.5 supports 29 languages. Add Kikuyu, Luo, Kamba, Kalenjin detection to the routing layer. For PMaaS this is a massive differentiator — candidate speaks to voters in their mother tongue. First in Kenya.
🧩 AI Agent Marketplace
Let instructors and admins create custom AI agents via a no-code UI (similar to OpenAI GPTs). Define system prompt, attach documents, choose model. Deploy as a named agent on the platform. Build agent economy inside i3.
📱 WhatsApp as Universal Interface
Since 90%+ Kenyans use WhatsApp, expose ALL i3 AI surfaces via WhatsApp: exam results, course content Q&A, policy bot, constituency feedback. One number. Zero app download needed. Uses existing n8n + WhatsApp Business API.
🔄 Model Fallback + Cost Routing
LiteLLM already supports fallbacks. Implement cost-aware routing: try Qwen local first (free) → if overloaded, fail to GLM-4 local → if complex query, escalate to watsonx/KIMI API. 80% cost reduction vs. pure API usage.
📊 AI Analytics for Educators
Langfuse already traces all LLM calls. Build an "AI Usage Dashboard" for instructors: which students are using AI Lab most, what topics are they stuck on, which exam questions generated the most hint requests → curriculum intelligence.
🛡️ i3 Trust Layer (Ethics Shield)
Extend the Admissions Lobster Trap firewall to ALL interfaces. Add: hate speech detection (NCIC compliance), hallucination scoring, source confidence score, and an "AI Authenticity Certificate" shown on every AI-generated output — building user trust.
🤖 Multi-Agent Collaboration
Deploy watsonx Orchestrate or LangGraph to chain agents: Research Agent → Draft Agent → Review Agent → Publish Agent. For PMaaS: Intel Agent → Narrative Agent → Approval Gate → Broadcast Agent. Fully automated with human gates at each approval step.
