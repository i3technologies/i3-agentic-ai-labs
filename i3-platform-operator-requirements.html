1 — PMaaS & Engage: Safaricom Daraja (M-Pesa)

Required for all M-Pesa payment collection (STK Push) and disbursements (B2C) in PMaaS and AfroERP.

RequirementPriorityEnvironment VariableProducts Affected
M-Pesa Shortcode — your Paybill or Till number CRITICAL MPESA_SHORTCODE PMaaS, AfroERP
M-Pesa Passkey — from Daraja portal sandbox/production CRITICAL MPESA_PASSKEY PMaaS, AfroERP
Consumer Key DONE DONE MPESA_CONSUMER_KEY Already set: p9MtTHfq0np8OnX…
Consumer Secret DONE DONE MPESA_CONSUMER_SECRET Already set: BtG0mgEEhtUd40…
How to get it 1. Go to developer.safaricom.co.ke → log in or register.
2. Create an App under My Apps → Create New App. Enable Lipa Na M-Pesa Online and B2C APIs.
3. For production, go to Go Live and complete KYB. You will receive your Shortcode and Passkey in the production credentials.
4. Apply the values:
oc patch secret pmaas-secrets -n i3-pmaas --type merge -p '{"stringData":{"MPESA_SHORTCODE":"YOUR_SHORTCODE","MPESA_PASSKEY":"YOUR_PASSKEY"}}'

2 — Engage: WhatsApp Business API (Meta)

Required for all WhatsApp message sending in Engage. Without this, only SMS is functional.

RequirementPriorityEnvironment VariableNotes
WhatsApp Access Token — permanent system user token CRITICAL WHATSAPP_TOKEN Generate a System User Token in Meta Business Suite → not your personal page token (expires in 60 days)
WhatsApp Phone Number ID — numeric ID from Business Manager CRITICAL WHATSAPP_PHONE_NUMBER_ID Found under Meta Business Suite → WhatsApp → Getting Started
WhatsApp Business Account ID (WABA ID) HIGH WHATSAPP_WABA_ID Required for template submission API calls
Webhook Verify Token — any random string you choose HIGH WHATSAPP_WEBHOOK_TOKEN Set the same value in Meta Developer Console → Webhooks → Verify Token
How to get it 1. Go to developers.facebook.com → My Apps → select or create an App with WhatsApp Business product.
2. Under WhatsApp → Getting Started find your Phone Number ID and WABA ID.
3. In Meta Business Suite → Settings → Users → System Users, create a system user with FULL CONTROL on the WABA, then generate a permanent token.
4. Apply to cluster:
oc patch secret engage-secrets -n i3-engage --type merge -p '{"stringData":{"WHATSAPP_TOKEN":"YOUR_TOKEN","WHATSAPP_PHONE_NUMBER_ID":"YOUR_ID"}}'

3 — Engage: Africa's Talking (SMS)

Required for all SMS sending in Engage. Without this, bulk SMS campaigns cannot be dispatched.

RequirementPriorityEnvironment VariableNotes
AT API Key CRITICAL AT_API_KEY Found in AT dashboard → Settings → API Key
AT Username CRITICAL AT_USERNAME Your Africa's Talking account username (not email)
AT Sender ID (optional) MEDIUM AT_SENDER_ID Register a custom alphanumeric sender ID at AT portal for branded SMSes; leave blank to use shared short code
How to get it 1. Register at africastalking.com → Create an account.
2. From the dashboard top-right → click your username → Settings → API Key → Generate.
3. For production SMS, go to SMS → Sender IDs and register your approved sender name (takes 1–3 business days with CA approval).
4. Apply:
oc patch secret engage-secrets -n i3-engage --type merge -p '{"stringData":{"AT_API_KEY":"YOUR_KEY","AT_USERNAME":"YOUR_USERNAME"}}'

4 — Engage: Brevo (Email Campaigns)

Required for email campaign sending from Engage. Without this, email channel is unavailable.

RequirementPriorityEnvironment VariableNotes
Brevo API Key (v3) HIGH BREVO_API_KEY Brevo (formerly Sendinblue) — needed for transactional email and newsletter campaigns
Sender Email HIGH BREVO_SENDER_EMAIL Must be a verified domain sender in Brevo (e.g. noreply@i3technologies.co.ke)
How to get it 1. Register at brevo.com → Log in → top-right menu → SMTP & API → API Keys → Create a New API Key.
2. Verify your sending domain: Senders & Domains → Domains → Add a domain. Add the DNS TXT/DKIM records cPanel provides to i3technologies.co.ke.
3. Apply:
oc patch secret engage-secrets -n i3-engage --type merge -p '{"stringData":{"BREVO_API_KEY":"YOUR_KEY","BREVO_SENDER_EMAIL":"noreply@i3technologies.co.ke"}}'

5 — AfroERP: KRA eTIMS Integration

Required for electronic tax invoice submission to KRA as mandated by Kenya Tax Procedures Act.

RequirementPriorityWhere to ConfigureNotes
eTIMS Device Serial Number (CU Serial) CRITICAL AfroERP Settings → KRA eTIMS Issued by KRA after device registration at iTax portal
Company KRA PIN CRITICAL AfroERP → Company → Tax ID field Your company's KRA PIN (format: A000000000A)
eTIMS API Username & Password CRITICAL ETIMS_USERNAME / ETIMS_PASSWORD Credentials from KRA eTIMS portal (itax.kra.go.ke)
How to get it 1. Log in to iTax (itax.kra.go.ke) with your company PIN and password.
2. Go to eTIMS → Device Registration and register your virtual eTIMS device (VSCU). You will receive a CU Serial Number.
3. Download and install the eTIMS VSCU software — AfroERP's API communicates with it locally or via the KRA cloud API endpoint.
4. Add the credentials to the AfroERP secrets:
oc patch secret afroerp-secrets -n i3-afroerp --type merge -p '{"stringData":{"ETIMS_USERNAME":"YOUR_PIN","ETIMS_PASSWORD":"YOUR_ITAX_PASS","ETIMS_CU_SERIAL":"YOUR_CU_SERIAL"}}'
