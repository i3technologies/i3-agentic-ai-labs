1. Accessing EvalOS

EvalOS is available at https://evalos.i3technologies.co.ke. Access is restricted to enrolled i3 students and staff only.

  1. Open the URL in your browser Chrome or Edge recommended. Disable browser extensions for best experience.
  2. Click "Sign in with i3 SSO" You will be redirected to the i3 Keycloak identity portal.
  3. Enter your i3 Technologies credentials Use the username and password issued to you by your i3 programme coordinator.
  4. You are redirected to your Dashboard All available practice sets are shown with your progress, scores, and attempt counts.

2. Your Dashboard

The Dashboard is your home screen. Each practice set appears as a card showing:

  • Exam code & title (e.g. C1000-207-SET7)
  • Question count, duration, and pass mark
  • Your best score and last score
  • Attempts used vs maximum — shown as filled/unfilled circles
  • Retake deadline — shown as an amber countdown badge for timed-retake exams (e.g. Set 7)
  • Prerequisite lock — 🔒 icon if a previous set must be passed first
ℹ️
Sets are sequential. You must score ≥90% on each set to unlock the next. Set 7 is unlocked once you pass Set 6 (or if Set 7 is your first set).

3. Practice Set 7 — Rules & Policies

Pass Mark  90%

You must answer at least 54 of 60 questions correctly to pass. This matches the rigor of the IBM C1000-207 certification exam.

Attempts  3 total

1 initial attempt + 2 retakes. Each attempt presents a fresh randomised draw from the Set 7 question bank with shuffled options.

48-Hour Retake Window  Time-Gated

Both retakes must be started within 48 hours of your first attempt. The clock starts the moment you click "Start Exam" for the first time. You can see the exact deadline on your dashboard card. Once 48 hours have elapsed, no further retakes are permitted regardless of attempts remaining.

Duration  90 minutes

60 questions · 90 minutes. The timer counts down in the exam interface. Submit before time expires or your answers will be auto-submitted.

4. Taking an Exam

  1. Click "Start Exam" (or "Retake") on the dashboard card For Set 7 retakes, the button only appears while the 48h window is open and you have attempts remaining.
  2. Read the exam brief page Confirm question count, duration, and pass mark before the timer starts.
  3. Answer each question MC questions: select ONE answer. MR (multi-response) questions: select ALL correct answers — these are labelled "Select all that apply."
  4. Navigate freely Use Previous / Next buttons. Revisit any question before submitting. Answered questions are highlighted in the progress bar.
  5. Submit when ready Click "Submit Exam" and confirm. Your attempt is graded instantly. The timer auto-submits at 00:00.

During the Exam — Important Rules

  • Stay on the exam tab. Tab switching is recorded as an integrity event and may trigger an admin review flag.
  • Full-screen is recommended. Exiting full-screen is logged.
  • No copy-paste. Clipboard events are monitored.
  • Stable internet required. Your answers are auto-saved every 30 seconds. If you lose connection, reopen the exam URL — your progress is preserved for 30 minutes.

5. Viewing Results & Certificates

After submitting, you are taken to the Results page automatically.

  • Overall score — percentage and pass/fail verdict
  • Domain breakdown — score per domain so you know where to focus
  • Correct / incorrect per question — with the right answer and explanation shown
  • AI Study Coach panel — a personalised 3-day study plan generated from your weak domains (see Section 6)
🏅
Digital Certificate. If you pass with ≥90%, a "Get Certificate" button appears. Click it to generate a PDF certificate with a unique verification code. Share the URL https://evalos.i3technologies.co.ke/verify/[code] so employers can verify your credential online.

Past results are always accessible from the dashboard Recent Attempts table → "View Results".

8. Frequently Asked Questions

Can I pause Set 7 mid-exam?

Yes. If you close the browser, your in-progress attempt is saved for up to 30 minutes. Return to the exam URL and click Resume. The countdown timer continues in the background — it does not pause.

I scored 89% on Set 7. Can I retake immediately?

Yes, as long as you have retake attempts remaining AND the 48-hour window has not closed. The retake button appears on your dashboard card with the deadline shown.

The "Retake window expired" message appeared but I still have attempts left. What do I do?

The 48-hour window is a hard rule set by your programme. Once it closes, remaining attempts cannot be used. Contact your i3 programme coordinator if you believe there was an error.

What is the difference between MC and MR questions?

MC (Multiple Choice) — exactly one correct answer. A wrong answer scores 0.
MR (Multiple Response) — two or more correct answers. You must select ALL correct answers for full marks; a partial selection scores 0.

Can I see the correct answers during the exam?

No. Correct answers and explanations are revealed only after you submit. This maintains the integrity of the practice environment.

How are multi-response (MR) questions scored?

Each MR question is all-or-nothing: you must select every correct option to receive the mark. Selecting some but not all correct options, or any wrong option, scores 0.

Can I retake an exam I already passed?

Yes — passed exams show a "Retake Exam" button. For Set 7 the 48-hour retake window applies to ALL retakes regardless of pass/fail on the initial attempt.

Where does my certificate go after I pass?

It is stored permanently in your account. Access it any time from your Results page or the Dashboard "Recent Attempts" table. A unique verification URL is included so employers can confirm it online.

Is my exam data private?

Yes. All data is stored within i3's private OpenShift cluster in Kenya. i3 Technologies complies with the Kenya Data Protection Act 2019. Exam monitoring signals are used solely for academic integrity and are reviewed only by authorised i3 staff.

I found a question that seems incorrect. How do I report it?

Use the AI Study Coach panel on the Results page — it includes a "Flag this question" option. Admin staff review all flags within 48 hours.
