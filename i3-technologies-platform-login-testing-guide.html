7 Preflight Verification (Before First Login)

Run these commands to confirm the cluster and routes are ready before attempting a browser login.

Check Keycloak is Running

oc get pods -n i3-auth
# Expected: 2 pods with STATUS = Running

Check SSO Route Resolves

curl -sk -o /dev/null -w "%{http_code}" https://sso.i3technologies.co.ke/
# Expected: 200 or 302

Check All Routes at Once

oc get routes -A --no-headers | grep "i3-" | awk '{print $1, $3}' | column -t

Run Full Automated Checklist

# Load environment first
. .\platform\scripts\load-env.ps1

# Run the 10-section post-deploy validation
.\platform\scripts\post-deploy-checklist.ps1

Provision Test Users (if not yet done)

# Set the Keycloak admin password first
$env:KEYCLOAK_ADMIN_PASSWORD = "<keycloak-admin-password>"

# Run provisioning — idempotent, safe to re-run
.\platform\scripts\provision-test-users.ps1
