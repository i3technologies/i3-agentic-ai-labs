7. Observations & Notes

#ObservationSeverityRecommendation
1 db.ts uses rejectUnauthorized: false with Crunchy Postgres CA cert. The comment acknowledges the self-signed chain and CA is pinned when PG_CA_CERT_PATH is set. LOW Acceptable for self-signed Crunchy CA. Ensure PG_CA_CERT_PATH is always set in production Deployment secret.
2 Study Coach route has maxDuration = 115s — covers LLM inference latency on CPU but is close to the 120s HAProxy cut-off. LOW Monitor p95 latency via Langfuse. Increase HAProxy timeout annotation if inference moves to GPU.
3 13 migration files present; no migration runner (Flyway/Liquibase) configured. Manual psql execution required. LOW All migrations are idempotent (IF NOT EXISTS). Consider adding Flyway or a Kubernetes Job for automated migration at pod startup.
4 Grading service is an external HTTP call to grading-service.i3-evalos.svc.cluster.local:8000. SAGA pattern correctly marks status as grading_failed on timeout/error and surfaces a retryable 503. INFO Pattern is correct. Ensure grading service pod is deployed and healthy in i3-evalos namespace.
5 Question dot navigator in exam UI only shows up to 12 dots. Sets with 60 questions show "+48" overflow indicator. INFO UX is functional. Consider expanding the question grid for power users with keyboard shortcuts.
6 AI question generation (/api/admin/generate-questions) stores ai_generated=true on questions. No post-generation review gate enforced in code. LOW Add an "AI Draft" status requiring admin approval before questions are marked is_active=true.
